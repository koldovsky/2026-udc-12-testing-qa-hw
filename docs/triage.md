    правильною.
  - Поїздки генерував `app/test/helpers/factory.js` через `Math.random()`: тривалість від 5 до 89 хв,
    момент взяття з 09:00 до 19:00 за Києвом (`factory.js:10-15`). У тесті 10 таких поїздок. Отже,
    тест падає лише тоді, коли серед 10 випадкових тривалостей трапиться 30 або 60 хв. Код

## 2. Тріаж падінь CI

Кожен прогін з `ci/` — окремий розділ. Клас — один із чотирьох: **код** (дефект у коді
застосунку), **тест** (дефект у тесті), **середовище** (інфраструктура: ОС, мережа,
ресурси, зовнішні сервіси…), **нестабільний тест** (той самий код то проходить, то ні).

Номери рядків логу — з `grep -n` над `ci/runs/run-NNNN.log`. **Відтворення** означає таке: кожну зміну
застосовано до окремої свіжої копії з `main` командою з `docs/walkthrough.md`:

```bash
rm -rf ../ws12-d-repro && mkdir -p ../ws12-d-repro && git archive main app ci | tar -x -C ../ws12-d-repro
cd ../ws12-d-repro && git init -q && git apply ci/changes/run-NNNN.diff && npm --prefix app test; cd -
```

Усі чотири дифи застосовуються до `main` без помилок. Відтворено 2026-11-06, Node v24.18.0. У CI був
v24.11.1, `ci/runs/*.log:108`.
