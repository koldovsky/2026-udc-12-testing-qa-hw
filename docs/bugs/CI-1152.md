# CI-1152: збір за неповернений велосипед не нараховується, якщо велосипед повернуто поза зоною

| Поле | Значення |
|---|---|
| **Правило специфікації** | T8 — «Збори T7 і T8 нараховуються незалежно один від одного: до однієї поїздки можуть застосовуватися обидва.» (`docs/spec/tariffs.md:121-122`); T7 — збір 150 грн (`:111`), T8 — 2 000 грн за поїздку понад 24 години (`:119`) |
| **Середовище** | прогін CI 1152 (`ci/runs/run-1152.log`: Ubuntu 24.04, образ `20261020.1`, Node v24.11.1); відтворено локально на чистій копії `main` (`git archive main app ci`), Node v26.13.0, Darwin 25.6.0 |
| **Серйозність** | висока — недобір 2 000,00 грн з кожної поїздки, що триває понад 24 години й закінчується поза зоною (збір за неповернений велосипед губиться, лишається лише 150 грн); не крашить, тож клієнти й служба підтримки помітять лише в чеку |
| **Частота** | завжди для поїздок понад 24 год із поверненням на `X01`–`X03` (відтворюється детерміновано) |
| **Знайдено** | прогін CI 1152: `ci/runs/run-1152.log:170` і `:189` — `app/test/unit/tariff.test.js` › `a bike kept over a day and left outside the zone pays both fees`, `1 !== 2` |
| **Виправлення** | не застосовано (за завданням diff у `main` не вноситься). Що змінити: у `feesFor` (`app/src/tariff.js`, зміна з PR #238, `ci/changes/run-1152.diff`) повернути два незалежні `if … push`, а не `if … return` / `if … return` |

## Кроки відтворення

1. Взяти чисту копію `main`: `mkdir -p ../ws12-d-repro && git archive main app ci | tar -x -C ../ws12-d-repro && cd ../ws12-d-repro && git init -q`.
2. Застосувати зміну з PR #238: `git apply ci/changes/run-1152.diff`.
3. Запустити тести: `npm --prefix app test`.
4. Запустити команду з розділу «Доказ» (до і після кроку 2).

## Очікуваний результат (за специфікацією)

Поїздка 16.09 07:00Z → 18.09 07:00Z (48 год > 24 год) на станцію `X03` (поза зоною, `docs/spec/tariffs.md:176`)
має два збори одночасно: `out-of-zone` 15 000 коп (T7, `:111`) і `unreturned` 200 000 коп (T8, `:119`).
Збори незалежні (`:121-122`).

## Фактичний результат

Після зміни з PR #238 збір повертає лише перший: `[{"code":"out-of-zone","amount":15000}]`.
Збір за неповернений велосипед (200 000 коп = 2 000 грн) губиться. Тест
`a bike kept over a day and left outside the zone pays both fees`: `actual: 1, expected: 2`.

## Доказ

```bash
node -e 'import("./app/src/tariff.js").then(({ quote }) => console.log(JSON.stringify(quote(
  { pickupAt: "2026-09-16T07:00:00Z", returnAt: "2026-09-18T07:00:00Z", bike: "classic", returnStation: "X03" },
  { type: "standard" }).fees)))'
```

До застосування `ci/changes/run-1152.diff` (чиста копія `main`):

```text

```

Після `git apply ci/changes/run-1152.diff`:

```text
[{"code":"out-of-zone","amount":15000}]
```

Рядок логу (`ci/runs/run-1152.log:170`, `:189`):

```text

```

## Мінімальний вхід

Будь-яка поїздка понад 24 години (1441 хв) з поверненням на `X01`, `X02` чи `X03`. Якщо повернути на станцію в зоні
(`S01`) — зміна поводиться правильно, бо тоді діє лише T8; якщо поїздка коротша за 24 год — лише T7.

## Додатково

- Тест, який зловив дефект, — наявний `app/test/unit/tariff.test.js:64` (назва вище); у `docs/test-quality.md`
  він значиться як слабкий (перевіряє лише `fees.length === 2`, без сум), але саме цього вистачило.

- Гіпотеза про місце в коді: `app/src/tariff.js`, `feesFor` — ранні `return` у зміні з PR #238.
