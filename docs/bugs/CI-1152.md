# CI-1152: Рефакторинг feesFor() губить другий збір при комбінації out-of-zone + unreturned

| Поле | Значення |
|---|---|
| **Правило специфікації** | T7 — «Повернення поза зоною: збір 150 грн.» `docs/spec/tariffs.md:112` + T8 — «Велосипед не повернено протягом 24 год: збір 2 000 грн.» `docs/spec/tariffs.md:119` |
| **Середовище** | CI run-1152, PR #238 `refactor/fees`, коміт `27fba14`, Node v24.11.1, Ubuntu (hosted runner) |
| **Серйозність** | висока — клієнт, який тримає велосипед понад добу та повертає поза зоною, платить лише один збір замість двох (недоотримання 2 000 грн) |
| **Частота** | завжди, коли обидві умови true: `zone === "out"` і `minutes > 1440` |
| **Знайдено** | `ci/runs/run-1152.log:170` — тест `a bike kept over a day and left outside the zone pays both fees`: actual 1, expected 2 |
| **Виправлення** | Повернути логіку з push замість early return у `feesFor()` |

## Кроки відтворення

1. Викликати `quote()` з поїздкою тривалістю > 24 годин і `returnStation` поза зоною (наприклад, `X03`).
2. Подивитися `result.fees.length`.

## Очікуваний результат (за специфікацією)

`fees.length === 2`: один збір `out-of-zone` (15000 копійок) і один `unreturned` (200000 копійок). T7 і T8 — незалежні правила.

## Фактичний результат

`fees.length === 1`: тільки `out-of-zone`. Збір `unreturned` ніколи не генерується.

## Доказ

`ci/changes/run-1152.diff`:

```diff
 function feesFor(minutes, zone) {
-  const fees = [];
-  if (zone === "out") fees.push({ code: "out-of-zone", amount: OUT_OF_ZONE_FEE });
-  if (minutes > UNRETURNED_AFTER_MINUTES) fees.push({ code: "unreturned", amount: UNRETURNED_FEE });
-  return fees;
+  if (zone === "out") return [fee("out-of-zone", OUT_OF_ZONE_FEE)];
+  if (minutes > UNRETURNED_AFTER_MINUTES) return [fee("unreturned", UNRETURNED_FEE)];
+  return [];
 }
```

Early `return` після першої умови означає, що коли `zone === "out"`, друга умова (`minutes > UNRETURNED_AFTER_MINUTES`) ніколи не перевіряється.

`ci/runs/run-1152.log:200-201`:
```
actual: 1,
expected: 2,
```

## Мінімальний вхід

```javascript
quote({
  pickupAt: "2026-09-16T07:00:00Z",
  returnAt: "2026-09-18T07:00:00Z",   // > 24 год
  bike: "classic",
  returnStation: "X03"                 // out-of-zone
}, { type: "standard" })
```

## Виправлення

Повернути послідовну перевірку обох умов з push:

```javascript
function feesFor(minutes, zone) {
  const fees = [];
  if (zone === "out") fees.push(fee("out-of-zone", OUT_OF_ZONE_FEE));
  if (minutes > UNRETURNED_AFTER_MINUTES) fees.push(fee("unreturned", UNRETURNED_FEE));
  return fees;
}
```
