# CI-1152: Поїздка поза зоною втрачає збір за неповернення

| Поле | Значення |
|---|---|
| **Правило специфікації** | **T7** задає збір 150 грн за повернення поза зоною (`docs/spec/tariffs.md:109–114`). **T8:** «Збори T7 і T8 нараховуються незалежно один від одного: до однієї поїздки можуть застосовуватися обидва» (`docs/spec/tariffs.md:117–121`). |
| **Середовище** | CI PR-коміт `27fba14`, merge-коміт `143f482`; Node v24.11.1, Ubuntu 24.04.3 (`ci/runs/run-1152.log:6–7, 93, 108`). Відтворення — копія `main` з `ci/changes/run-1152.diff`. |
| **Серйозність** | Висока: для поїздки понад добу поза зоною губиться збір 2 000 грн; користувачу не нараховується належна сума. |
| **Частота** | Завжди для поїздки, що одночасно триває понад 24 години та повернута поза зоною. |
| **Знайдено** | CI-1152: `ci/runs/run-1152.log:170, 186–190`; тест `app/test/unit/tariff.test.js` › `a bike kept over a day and left outside the zone pays both fees`. |
| **Виправлення** | Не виправлено тут: PR diff не переносився в `main`. Зберегти два незалежні `if` у `feesFor` та додавати обидва збори до масиву, а не повертати після першого збігу. |

## Кроки відтворення

1. Створити окрему чисту копію `main` з `app/` і `ci/`.
2. У копії виконати `git apply ci/changes/run-1152.diff`.
3. Виконати `node --test app/test/unit/tariff.test.js`.

## Очікуваний результат (за специфікацією)

Тестова поїздка триває 48 годин і завершується поза зоною. Застосовуються обидва
незалежні збори: `out-of-zone` — 15 000 коп. і `unreturned` — 200 000 коп. Денний ліміт
обмежує погодинну частину до 30 000 коп.; очікуваний підсумок — 245 000 коп. (2 450 грн).

## Фактичний результат

`feesFor` повертає лише `out-of-zone`. Тест бачить один збір замість двох (`1 !== 2`), а
сума за неповернений велосипед не додається.

## Доказ

```bash
git apply ci/changes/run-1152.diff
node --test app/test/unit/tariff.test.js
```

```text
✖ a bike kept over a day and left outside the zone pays both fees
AssertionError: Expected values to be strictly equal:
1 !== 2
ℹ tests 11
ℹ pass 10
ℹ fail 1
```

CI також показує цю ж помилку: `ci/runs/run-1152.log:189` — `1 !== 2`. Diff змінює два
незалежні додавання зборів на ранні повернення (`ci/changes/run-1152.diff`, hunk у
`app/src/tariff.js` біля `feesFor`).

## Мінімальний вхід

Класичний велосипед: `pickupAt: 2026-09-16T07:00:00Z`, `returnAt: 2026-09-18T07:00:00Z`,
`returnStation: X03`. Тривалість — 48 годин, станція повернення поза зоною.

## Додатково

Повний `npm test` на копії з diff також упав на цій перевірці; окремий запуск unit-файлу
ізолює помилку від випадкового тесту квитанцій. `npm audit` у CI не дістався до audit
endpoint (`ci/runs/run-1152.log:138–143`), але крок має `continue-on-error: true` і це не
причина падіння тестів.
