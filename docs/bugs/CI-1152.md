# CI-1152: a long ride returned outside the zone loses the unreturned fee

| Field | Value |
|---|---|
| Specification | T7 and T8, "Збори T7 і T8 нараховуються незалежно один від одного"; docs/spec/tariffs.md:111-122 |
| Environment | main 4606c72 plus ci/changes/run-1152.diff; synthetic CI Ubuntu Node 24.11.1, reproduction Windows Node v25.8.0 |
| Severity | High: a 200000-kopeck unreturned fee is omitted |
| Frequency | Always when both fee conditions apply |
| Found | ci/runs/run-1152.log:170,185-201; test: a bike kept over a day and left outside the zone pays both fees |
| Fix | Proposed only: restore independent accumulating fee checks; do not apply CI diff to participant branch |

## Reproduction steps

1. Create a new temporary directory and extract original main app and ci into it.
2. Run the following in Git Bash from that extracted root.

```bash
git apply ci/changes/run-1152.diff
node --test --test-name-pattern='a bike kept over a day' app/test/unit/tariff.test.js
node --input-type=module -e 'import {quote} from "./app/src/tariff.js";console.log(JSON.stringify(quote({pickupAt:"2026-09-16T07:00:00Z",returnAt:"2026-09-18T07:00:00Z",bike:"classic",returnStation:"X03"},{type:"standard"})));'
```

## Expected result (specification)

48 hours, classic, standard, X03: base 240000, time capped at 30000 (T6:100-103), outside fee 15000 (T7:111-112), unreturned fee 200000 (T8:119-122), total 245000.

## Actual result

```json
{"minutes":2880,"timeCharge":240000,"discounts":[{"code":"day-cap","amount":210000}],"fees":[{"code":"out-of-zone","amount":15000}],"total":45000}
```

The test fails with fees.length=1 rather than 2; the total is 45000, undercharging 200000.

## Evidence

- ci/runs/run-1152.log:200-201: actual 1, expected 2.
- ci/changes/run-1152.diff:15-17: outside-zone branch returns before evaluating the unreturned branch.
- ai-runs/d-ci-reproductions.txt: run-1152 git apply succeeds and the focused test exits 1.
- ai-runs/d-ci-1152-quote.txt: exact quote above.

## Minimal input

A classic standard ride longer than 24 h, returned at X01/X02/X03; use an integral extra minute to avoid Q-3.
Removing either condition makes the early-return implementation emit the only applicable fee correctly.

Audit ETIMEDOUT is logged first (run-1152.log:137-142), but line 143 explicitly continues; the blocking error is the assertion at 187 and test-step exit at 205.
