## Кроки відтворення

1. Свіжа копія `main` з `ci/` і застосована зміна прогону:
   ```bash
   rm -rf ../ws12-d-repro && mkdir -p ../ws12-d-repro && git archive main app ci | tar -x -C ../ws12-d-repro
   cd ../ws12-d-repro && git init -q && git apply ci/changes/run-1152.diff
   ```
2. `npm --prefix app test` — червоний тест `a bike kept over a day and left outside the zone pays both fees`.
3. Або напряму: поїздка класичним велосипедом, стандартний користувач, 16.09 07:00Z → 17.09 08:00Z (25 год), повернення на X03 (команда нижче).

## Очікуваний результат (за специфікацією)

25 год → 50 блоків = 125000 → денний ліміт 30000 (T6, `:100-101`); повернення на X03 (поза зоною,
`:176`) → збір 15000 (T7, `:111-112`); понад 24 год → збір 200000 (T8, `:119-120`); обидва збори
незалежно (`:121-122`) → `fees` = [15000, 200000], до сплати **245000** (2 450,00 грн).

## Фактичний результат

`fees: [{ code: "out-of-zone", amount: 15000 }]` — без `unreturned`; `total: 45000` (450,00 грн).

+  if (zone === "out") return [fee("out-of-zone", OUT_OF_ZONE_FEE)];
+  if (minutes > UNRETURNED_AFTER_MINUTES) return [fee("unreturned", UNRETURNED_FEE)];

## Мінімальний вхід

Тривалість 1441 хв (24 год 1 хв) і станція X01 / X02 / X03. Якщо повернути в зоні (S01–S08) —
