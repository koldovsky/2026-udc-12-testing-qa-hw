## Мінімальний вхід

Поїздка > 1 440 хв **і** станція поза зоною. Якщо виконується лише одна умова (лише поза
зоною або лише понад добу), результат правильний: ранній `return` повертає саме той єдиний
збір. Тому інші тести на збори в прогоні зелені (`run-1152.log:155`, `:168`).

## Додатково

- Перша помилка в лозі — `npm error code ENOAUDIT` (`run-1152.log:137`) — не причина:
  `continue-on-error` (`:143`).
- Порядок перевірок у новому коді додатково приховує T8: збір «поза зоною» перевіряється
  першим, тож для поїздки поза зоною T8 не досягається ніколи.
