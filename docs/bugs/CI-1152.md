# CI-1152: поїздка понад добу поза зоною втрачає збір 2 000 грн

| Поле | Значення |
|---|---|
| **Правило специфікації** | T7: «нараховується збір за перевезення велосипеда — **150 грн**» (`docs/spec/tariffs.md:109-112`). T8: «Якщо поїздка триває понад 24 години, нараховується збір за неповернений велосипед — **2 000 грн**»; «Збори T7 і T8 нараховуються незалежно один від одного» (`:117-122`). |
| **Середовище** | CI: hosted Ubuntu, Node 24.x (`ci/README.md:14-16`), PR #238 / `27fba14` поверх `main` (`4606c72`), зміна `ci/changes/run-1152.diff`. Локальне відтворення: Darwin, Node v26.9.0, окрема копія `main` + цей diff. |
| **Серйозність** | Висока: для кожної поїздки понад 24 год поза зоною підсумок занижено на 200 000 коп. (2 000 грн); збір T8 відсутній у чеку. |
| **Частота** | Завжди, коли одночасно `zone === "out"` і тривалість понад 1440 хв. |
| **Знайдено** | `ci/runs/run-1152.log:186-205`: тест `a bike kept over a day and left outside the zone pays both fees`, `1 !== 2`. |
| **Виправлення** | У PR відновити незалежне додавання зборів та повернути список після обох умов. Diff до `main` **не застосовано**; виправлення PR ще не зроблено. |

## Кроки відтворення

1. Створити **окрему** теку з `git archive main app ci` та `git init` у ній.
2. У цій теці виконати `git apply ci/changes/run-1152.diff` і `npm --prefix app test`: 19 тестів пройшли, один упав з `1 !== 2` (той самий, що в CI).
3. У цій теці виконати наведену нижче команду для 25-годинної поїздки з поверненням на X02 поза зоною.

## Очікуваний результат за T6–T8

25 год = 1500 хв = 50 блоків classic × 2500 = 125000 коп. Денний ліміт T6 зменшує погодинну плату до 30000 коп. T7 додає 15000 коп., T8 — 200000 коп. Разом **245000 коп. (2450,00 грн)** і два окремі елементи `fees`. T8 прямо дозволяє обидва збори в одній поїздці (`docs/spec/tariffs.md:117-122`); ліміт не поширюється на збори (`:99-103`).

## Фактичний результат

Код PR повертає тільки `out-of-zone` 15000 коп. і підсумок **45000 коп. (450,00 грн)**. Збір `unreturned` 200000 коп. пропадає. Це відповідає ранньому `return` після перевірки зони в `ci/changes/run-1152.diff:15-16`.

## Доказ

Після застосування diff до окремої копії `main`:

```bash
node --input-type=module -e 'import { quote } from "./app/src/tariff.js"; console.log(JSON.stringify(quote({ pickupAt: "2026-09-21T09:00:00Z", returnAt: "2026-09-22T10:00:00Z", bike: "classic", returnStation: "X02" }, { type: "standard" })))'
```

```text
{"minutes":1500,"timeCharge":125000,"discounts":[{"code":"day-cap","amount":95000}],"fees":[{"code":"out-of-zone","amount":15000}],"total":45000}
```

У CI `ci/runs/run-1152.log:186-205` показує один збір замість двох; помилка audit перед цим не зупиняла job, бо мала `continue-on-error` (`:143`).

## Мінімальний вхід

Для прояву дефекту достатньо будь-якої коректної поїздки **понад 24 години** зі станцією поза зоною; 25 год вище — простий приклад. Якщо змінити X02 на внутрішню станцію S01, спрацює лише T8; якщо скоротити тривалість до 24 год, спрацює лише T7. Дефект виявляється саме на перетині двох умов.

## Додатково

Наявний тест перевіряє тільки `fees.length`; для стійкого захисту слід також перевіряти `code`, `amount` кожного збору та `total` за T7/T8. Файл `app/src/tariff.js` у цьому репозиторії вже має правильне незалежне накопичення; дефект містить запропонований PR diff, який тут збережено лише як вхід для аналізу.
