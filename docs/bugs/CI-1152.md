# CI-1152: рефакторинг зборів робить T7 і T8 взаємовиключними

| Поле | Значення |
|---|---|
| **Правило специфікації** | T7: якщо велосипед повернуто на точку поза зоною обслуговування, нараховується збір 150 грн (`docs/spec/tariffs.md:109–115`). T8: якщо поїздка триває понад 24 години, нараховується збір 2000 грн додатково до погодинного нарахування, обмеженого T6; збори T7 і T8 нараховуються незалежно й можуть застосовуватися одночасно (`docs/spec/tariffs.md:117–125`). |
| **Середовище** | CI run 1152: Ubuntu 24.04.3 (`ci/runs/run-1152.log:9–18`), Node.js v24.11.1 (`ci/runs/run-1152.log:195–196`), CI checkout commit `143f4823e606aa48dc1b31a2e197e60918cc7f33` (`ci/runs/run-1152.log:65–67`). |
| **Серйозність** | **Висока:** для поїздки, яка одночасно повертається поза зоною й триває понад 24 години, система втрачає збір 15000 копійок. Це безпосередньо змінює суму до сплати та порушує два тарифні правила. |
| **Частотність** | За умови: кожне виконання сценарію з обома умовами відтворює дефект. CI run 1152 зафіксував 1 падіння тесту з 20 (`ci/runs/run-1152.log:207–212`). |
| **Знайдено** | CI run 1152: `ci/runs/run-1152.log:183–204`, тест `test/unit/tariff.test.js:64:1` у checkout CI. |

## Кроки відтворення

Виконати в окремій копії початкової гілки `main`, щоб не використовувати поточний виправлений робочий каталог:

```bash
git clone <репозиторій> ci-1152-repro
cd ci-1152-repro
git checkout main
git apply ci/changes/run-1152.diff
cd app
npm test
```

У цьому робочому середовищі повторний запуск у правильно підготовленій окремій копії `main` не заявляю як виконаний результат. Наведена команда `git apply ci/changes/run-1152.diff` є точною процедурою з умов задачі; фактичний підтверджений результат — із CI-логу run 1152 нижче.

## Конкретні вхідні дані

```js
{
  pickupAt: "2026-09-16T07:00:00Z",
  returnAt: "2026-09-18T07:00:00Z",
  bike: "classic",
  returnStation: "X03"
}
{ type: "standard" }
```

`X03` — точка поза зоною з додатка A специфікації; тривалість поїздки — 48 годин, тобто одночасно виконуються T7 і T8. Це той самий сценарій, на який посилається тест із CI (`test/unit/tariff.test.js:64:1`).

## Очікуваний результат (за специфікацією)

Для поїздки з тесту `a bike kept over a day and left outside the zone pays both fees`:

- тривалість — 48 годин, тобто погодинне нарахування обмежується денним лімітом T6: 30000 коп.;
- T7 додає 15000 коп. за повернення поза зоною;
- T8 додає 200000 коп. за неповернення понад 24 години;
- очікуваний список зборів містить два елементи: `out-of-zone` і `unreturned`;
- загальна сума має бути `30000 + 15000 + 200000 = 245000` коп. (`2450,00 грн`).

## Фактичний результат

CI отримав один збір замість двох:

```text
test/unit/tariff.test.js:64:1
a bike kept over a day and left outside the zone pays both fees
AssertionError [ERR_ASSERTION]: Expected values to be strictly equal:
1 !== 2
actual: 1
expected: 2
```

Доказ: `ci/runs/run-1152.log:183–204`, зокрема фактичне `1`, очікуване `2` на рядках `ci/runs/run-1152.log:200–204`. Усього в job було 19 успішних і 1 невдалий тест (`ci/runs/run-1152.log:176–187`). Попередження `npm audit` не є причиною падіння: воно позначене як `continue-on-error` (`ci/runs/run-1152.log:132–143`).

## Доказ дефектної зміни

Початковий код накопичував обидва збори незалежними умовами:

```diff
-  const fees = [];
-  if (zone === "out") fees.push({ code: "out-of-zone", amount: OUT_OF_ZONE_FEE });
-  if (minutes > UNRETURNED_AFTER_MINUTES) fees.push({ code: "unreturned", amount: UNRETURNED_FEE });
-  return fees;
```

Зміна в `ci/changes/run-1152.diff:9–22` замінила незалежні `push` на взаємовиключні `return`:

```diff
+  if (zone === "out") return [fee("out-of-zone", OUT_OF_ZONE_FEE)];
+  if (minutes > UNRETURNED_AFTER_MINUTES) return [fee("unreturned", UNRETURNED_FEE)];
```

Коли `zone === "out"` і тривалість перевищує 24 години, виконується перший `return`, тому перевірка T8 уже не досягається. Це точно пояснює результат `1 !== 2` у CI.

## Мінімальне виправлення

Зберегти масив зборів і додавати елементи окремими `if` без раннього `return`, наприклад повернутися до незалежної структури:

```js
const fees = [];
if (zone === "out") fees.push({ code: "out-of-zone", amount: OUT_OF_ZONE_FEE });
if (minutes > UNRETURNED_AFTER_MINUTES) fees.push({ code: "unreturned", amount: UNRETURNED_FEE });
return fees;
```

Цей звіт не вносить змін до production-коду.
