## Steps to reproduce

1. Make a fresh copy of `main` with the change of the run (from the repo root):
   ```bash
   rm -rf ../ws12-d-repro && mkdir -p ../ws12-d-repro && git archive main app ci | tar -x -C ../ws12-d-repro
   cd ../ws12-d-repro && git init -q && git apply ci/changes/run-1152.diff
   ```
2. Run the tests: `npm --prefix app test`. The test `a bike kept over a day and left outside the
   zone pays both fees` fails with `1 !== 2`.
3. In the same folder, call `quote` for a standard rider on a classic bike, pickup
   `2026-09-16T07:00:00Z`, return `2026-09-17T07:01:00Z`, station `X03`, and read `fees` and `total`.

## Expected result (per spec)

24 h 01 min is 1441 min (`docs/spec/tariffs.md:45-47`), 49 started blocks of 30 min, 49 × 25 UAH =
1 225 UAH (`:62, 66`), capped at 300 UAH a day (`:100-101`). X03 is outside the zone
(`:176`), so the T7 fee of 150 UAH applies (`:111-112`). The ride is over 24 hours, so the T8 fee of
2 000 UAH applies too (`:119-120`), independently of T7 (`:121-122`).
`fees` are `out-of-zone` 15000 and `unreturned` 200000; `total` is 30000 + 15000 + 200000 = 245000
(2 450,00 UAH).

## Actual result

`fees` hold `out-of-zone` 15000 only; `unreturned` is missing. `total` is 45000 (450,00 UAH).

## Minimal input

Standard rider, classic bike, pickup `2026-09-16T07:00:00Z`, return `2026-09-17T07:01:00Z`
(1441 min), station `X03`. Both conditions are needed: with an in-zone station (`S03`) the ride has
only the T8 fee and the result is the same as on `main` (230000); with a ride of 20 min at `X03` it
has only the T7 fee and the result is the same too (17500).

## Additional

- Location: `feesFor` in `app/src/tariff.js` (`ci/changes/run-1152.diff`, hunk
  `@@ -102,11 +102,15 @@`). `if (zone === "out") return [fee("out-of-zone", OUT_OF_ZONE_FEE)];`
  returns before the T8 line is reached. The comment the PR adds above the function, «Fees of a
  ride: T7 out of zone, T8 over 24 h», describes both fees.
- What to change, keeping the PR's `fee()` helper:
  ```js
  function feesFor(minutes, zone) {
    const fees = [];
    if (zone === "out") fees.push(fee("out-of-zone", OUT_OF_ZONE_FEE));
    if (minutes > UNRETURNED_AFTER_MINUTES) fees.push(fee("unreturned", UNRETURNED_FEE));
    return fees;
  }
  ```
- Tests that catch it: on `main`, the unit test above. With the change applied to this branch
  (`9126021`), also the spec tests `T8: TC-68`, `T8: TC-100` and `T9: TC-78` (the last block of the
  evidence).
- The AI's CI triage classed this run as a code defect too and proposed the same change
  (`ai-runs/d-ci-first.md:169-213`); it did not run the changed code.
