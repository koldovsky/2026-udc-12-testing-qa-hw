# BUG-4: пільговику вдвічі знижують збори за повернення поза зоною і за неповернений велосипед

| Поле | Значення |
|---|---|
| **Правило специфікації** | T5 — «Пільга не поширюється на збори (T7, T8)» (`docs/spec/tariffs.md:87`); «Збори не є погодинним нарахуванням» (`:31`) |
| **Середовище** | дефект — у `main` (`4606c72`), відтворено на копії `git archive main app`; Node v26.3.0; Windows 10 (Git Bash) |
| **Серйозність** | висока — недобір 75 грн за кожне повернення поза зоною і 1 000 грн за кожен неповернений велосипед пільговиком (або абонентом із пільгою, коли перемагає пільга) |
| **Частота** | завжди, коли застосовано план `reduced` і є збір |
| **Знайдено** | `app/test/spec/tariff.test.js` › `T5: TC-30 пільговий, 20 хв, X01 → 1250 + збір 15000 без знижки = 16250`, `T5: TC-31 пільговий, 25 год → ліміт 30000 + збір 200000 без знижки = 230000` (`ai-runs/b2-run.txt`) |
| **Виправлення** | `d9b8370 fix(T5): reduced fare no longer discounts out-of-zone and unreturned fees` |

## Кроки відтворення

1. На коді з `main` порахувати поїздку класичним велосипедом, пільговий користувач,
   взяття `2026-09-16T07:00:00Z`, повернення `2026-09-16T07:20:00Z` (20 хв), станція X01
   (поза зоною).
2. Подивитися `fees` і `total`.

## Очікуваний результат (за специфікацією)

20 хв → 1 блок 2500 (T3) − 50 % (T5) = 1250; збір поза зоною **15000** без знижки (T7 `:111-112`,
T5 `:87`) → до сплати **16250**.

## Фактичний результат

`fees: [{ code: "out-of-zone", amount: 7500 }]`, `total: 8750`.

## Доказ

```bash
node -e 'import("./app/src/tariff.js").then(({ quote }) => console.log(JSON.stringify(quote(
  { pickupAt: "2026-09-16T07:00:00Z", returnAt: "2026-09-16T07:20:00Z", bike: "classic", returnStation: "X01" },
  { type: "reduced" }))))'
```

До виправлення (копія `main`):

```text
{"minutes":20,"timeCharge":2500,"discounts":[{"code":"reduced","amount":1250}],"fees":[{"code":"out-of-zone","amount":7500}],"total":8750}
```

Після виправлення (`1b3e725`):

```text
{"minutes":20,"timeCharge":2500,"discounts":[{"code":"reduced","amount":1250}],"fees":[{"code":"out-of-zone","amount":15000}],"total":16250}
```

## Мінімальний вхід

Пільговий користувач, поїздка понад 2 хв (щоб план `reduced` мав ненульову знижку),
повернення на X01–X03 або тривалість понад 24 год. За поїздки ≤ 2 хв план `none`, і збір
повний — дефект зникає (тому кейс A1 H11 «випадково» правильний).
