## Кроки відтворення

1. Створіть копію початкового коду: `mkdir -p ../ws12-main && git archive main app | tar -x -C ../ws12-main`.
2. Розрахуйте поїздку пільгового користувача на класичному велосипеді: взяття 16.09.2026 10:00:00,
   повернення 10:40:00 за Києвом, точка поза зоною X01.
3. Порівняйте суму збору (`fees`) і `total` з очікуваними.

## Очікуваний результат (за специфікацією)

40 хв — 2 блоки = 50 грн, пільга 50 % → 25 грн (`docs/spec/tariffs.md:93`). Збір поза зоною 150 грн
(`:112`), на нього пільга не поширюється (`:87`). Разом: 2500 + 15000 = **17500 коп.**

## Фактичний результат

Збір `out-of-zone` 7500 коп. замість 15000, `total` 10000 коп.

## Мінімальний вхід

Пільговий користувач, класичний велосипед, взяття 10:00:00, повернення **10:03:00**, точка **X01**.
Результат на початковому коді за інших умов (та сама команда, змінено лише вказане поле):

| Вхід | Початковий код | За специфікацією |
|---|---|---|
| пільговий, X01, 3 хв | збір 7500, сума 8750 | збір 15000, сума 16250 |
| пільговий, S01, 3 хв | збору немає, сума 1250 | збору немає, сума 1250 |
| стандартний, X01, 3 хв | збір 15000, сума 17500 | збір 15000, сума 17500 |
| пільговий, X01, 1 хв (хибний старт) | збір 15000, сума 15000 | збір 15000, сума 15000 |

Дефект зникає, якщо збору немає, якщо користувач не пільговий або якщо за хибного старту знижка
дорівнює нулю.
