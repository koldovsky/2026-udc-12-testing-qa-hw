# BUG-4: пільговику вдвічі зменшують збори за повернення поза зоною і за неповернений велосипед

| Поле | Значення |
|---|---|
| **Правило специфікації** | T5 — «Пільга не поширюється на збори (T7, T8)» (`docs/spec/tariffs.md:87`); збір T7 — 150 грн (`:112`), T8 — 2 000 грн (`:119`–`:120`) |
| **Середовище** | дефект — `main` `4606c72` (`app/src/` той самий до `b0066a1`); Node v24.16.0; Windows 11 Home 10.0.26200, Git Bash |
| **Серйозність** | висока — коли обрано план «пільга», користувач платить 75 грн замість 150 грн за повернення поза зоною і 1 000 грн замість 2 000 грн за неповернений велосипед. Збори — стимул повертати велосипед у зону й вчасно; громада недоотримує половину збору щоразу, коли обрано пільгу (пільговик або абонент із пільгою, для якого пільга вигідніша) |
| **Частота** | завжди, коли застосовано пільговий тариф (пільговик або абонент із пільгою, для якого пільга вигідніша) і є збір; не проявляється, якщо погодинне нарахування 0 (тоді план «пільга» не обирається: напр. пільговик, 1 хв, X03 — `total` 15000 в обох версіях) |
| **Знайдено** | `app/test/spec/t5-reduced-fare.test.js` › `T5: TC-40 — пільг., клас., 20 хв, X03: збір T7 без знижки → 16250` (`ai-runs/b2-run.txt`); той самий дефект — TC-41, TC-42; видно й у TC-16 |
| **Виправлення** | `9f3f8c1` fix(T5): reduced fare no longer reduces T7 and T8 fees |

## Кроки відтворення

1. З кореня репо зробіть копію початкового коду (`main` = `4606c72`):
   `mkdir -p ../ws12-main && git archive main app | tar -x -C ../ws12-main`.
2. У `../ws12-main` порахуйте поїздку: класичний велосипед, пільговий тариф, 16.09.2026
   10:00:00 → 10:20:00 за Києвом (`07:00:00Z` → `07:20:00Z`), повернення на X03 (поза зоною) —
   команда в «Доказі».
3. Порівняйте збір `out-of-zone` і `total` з очікуваним.

## Очікуваний результат (за специфікацією)

20 хв — один блок, 2500 (`:62`, `:66`); пільга −50 % на погодинне (`:86`): 1250. X03 — поза зоною
(`:176`), збір 15000 (`:112`), і пільга на нього не поширюється (`:87`). **`total` = 1250 + 15000 =
16250** (162,50 грн).

## Фактичний результат

`fees: [{ code: "out-of-zone", amount: 7500 }]`, `total: 8750` — збір зменшено вдвічі.

## Мінімальний вхід

Класичний, пільговий тариф, 20 хв, повернення на X03. Дефект зникає, якщо повернути в зону (S01:
зборів немає, 1250 в обох версіях) або взяти стандартний тариф (2500 + 15000 = 17500 в обох
версіях).
