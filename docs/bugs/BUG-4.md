# BUG-4: пільга помилково зменшує збір за повернення поза зоною

| Поле | Значення |
|---|---|
| **Правило специфікації** | T5: «Пільга не поширюється на збори (T7, T8)» — `docs/spec/tariffs.md:84-87`. T7 встановлює 150 грн — `docs/spec/tariffs.md:109-115`. |
| **Середовище** | Початковий код `main` = `4606c72`; Node `v26.9.0`; Darwin. |
| **Серйозність** | Висока: збір T7 зменшено на 75 грн; та сама гілка зменшувала і збір T8 на 1000 грн. |
| **Частота** | Завжди за пільгового плану й застосовного збору. |
| **Знайдено** | `app/test/spec/tariffs.test.js` › `T5, T7: TC-16 student pays the full zone fee` у `ai-runs/b2-run.txt`. |
| **Виправлення** | `41178a8` — `fix(T5): keep fees outside the reduced fare`. |

## Кроки відтворення

1. Із кореня репо створити копію початкового коду: `mkdir -p ../ws12-main`; `git archive main app | tar -x -C ../ws12-main`.
2. У корені `../ws12-main` виконати команду з розділу «Доказ». Для звіту копія була в `/private/tmp/ws12-main`.

## Очікуваний результат (за специфікацією)

30 хв класичним — 2500 коп.; студент сплачує половину погодинної плати, 1250 коп. за T5. X01 поза зоною (`docs/spec/tariffs.md:174`), тому незалежний збір T7 = 15000 коп. Підсумок **16250** коп.; збір не зменшується (`docs/spec/tariffs.md:86-87`, `:111-115`).

## Фактичний результат до виправлення

Знижка на час 1250 коп. правильна, але збір у відповіді — лише 7500 коп., підсумок **8750**. Початковий `app/src/tariff.js:63-65` помилково застосовував пільгові 50 % до кожного збору.

## Доказ

Команда з кореня копії `main`:

```bash
node --input-type=module -e 'import { quote } from "./app/src/tariff.js"; const r=quote({pickupAt:"2026-09-16T10:00:00+03:00",returnAt:"2026-09-16T10:30:00+03:00",bike:"classic",returnStation:"X01"},{type:"reduced"}); console.log(JSON.stringify({discounts:r.discounts,fees:r.fees,total:r.total}));'
```

```text
{"discounts":[{"code":"reduced","amount":1250}],"fees":[{"code":"out-of-zone","amount":7500}],"total":8750}
```

На виправленому коді: `{"discounts":[{"code":"reduced","amount":1250}],"fees":[{"code":"out-of-zone","amount":15000}],"total":16250}`.

## Мінімальний вхід

Пільговий користувач, класичний велосипед, 30 хв, повернення на X01. Для повернення на S02 помилки збору немає.

## Додатково

Наявний `app/test/unit/tariff.test.js` › `reduced fare for a ride returned outside the zone` очікував 7500 коп. збору. У коміті `41178a8` тест збережено, очікування змінено на 15000 коп. збору і 17500 коп. підсумку для його 40-хвилинного входу.
