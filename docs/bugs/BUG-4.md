# BUG-4: Пільговий тариф зменшує збори T7/T8 удвічі

| Поле | Значення |
|---|---|
| **Правило специфікації** | T5 — «Пільга не поширюється на збори (T7, T8)» (`docs/spec/tariffs.md:87`) |
| **Середовище** | код з `main` (`4606c72`), Node v24.16.0, Windows 11 (Git Bash) |
| **Серйозність** | висока: з кожного позазонного повернення пільговика сервіс втрачає 75 грн (7500 коп.), з кожного неповерненого велосипеда — 1000 грн (100000 коп.); збори — компенсація реальних витрат і не мають знижуватися |
| **Частота** | завжди, коли для поїздки переміг план «пільга» і є збір T7 або T8 |
| **Знайдено** | `app/test/spec/discounts.test.js` › `T5: reduced, classic, 20 min, returned out of zone — the fee is NOT discounted: 1250 + 15000 → 16250 (TC-19)` (прогін `ai-runs/b2-run.txt`) |
| **Виправлення** | `120d098 fix(T5): пільга не поширюється на збори T7 і T8` |

## Кроки відтворення

1. Взяти код із `main` (`mkdir -p ../ws12-main && git archive main app | tar -x -C ../ws12-main`).
2. Порахувати вартість поїздки пільговика 20 хв з поверненням на точку X01 (команда нижче).

## Очікуваний результат (за специфікацією)

Погодинне: 1 блок = 2500 − 50 % = 1250 (T5); збір за повернення поза зоною —
**повні 15000** (T7, `docs/spec/tariffs.md:111-112`; пільга на збори не діє,
`:87`) → разом **16250 коп.**

## Фактичний результат

Збір зменшено вдвічі: `fees = [{ "out-of-zone": 7500 }]`, `total = 8750`.

## Доказ

```bash
cd ../ws12-main && node -e 'import("./app/src/tariff.js").then(({ quote }) => { const q = quote({ pickupAt: "2026-09-16T07:00:00Z", returnAt: "2026-09-16T07:20:00Z", bike: "classic", returnStation: "X01" }, { type: "reduced" }); console.log(JSON.stringify({ timeCharge: q.timeCharge, discounts: q.discounts, fees: q.fees, total: q.total })); })'; cd -
```

```text
{"timeCharge":2500,"discounts":[{"code":"reduced","amount":1250}],"fees":[{"code":"out-of-zone","amount":7500}],"total":8750}
```

Після виправлення — `fees:[{"code":"out-of-zone","amount":15000}]`, `total = 16250`.

## Мінімальний вхід

Пільговик + будь-який збір. Поміняйте категорію на `standard` або поверніть у
зону — дефект зникає. У абонента з пільгою дефект з'являється лише тоді, коли
переміг саме план «пільга» (довга поїздка).

## Додатково

Причина — мапінг зборів у `quote`: `plan.code === "reduced" ? fee − 50 % : fee`
(`app/src/tariff.js:63-65` на `main`). Наявний тест `app/test/unit/tariff.test.js`
› «reduced fare for a ride returned outside the zone» стверджував половинний
збір — оновлено за специфікацією в коміті виправлення. Тест «з коду»
`ai-runs/b1-from-code/tariff.test.js` › «пільговий план зменшує збори на 50%»
зафіксував дефект як норму (червоний у `ai-runs/b1-rerun.txt`).
