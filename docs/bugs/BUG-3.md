# BUG-3: абонент їде на електровелосипеді перші 45 хв безкоштовно, хоча має лише знижку 20 %

| Поле | Значення |
|---|---|
| **Правило специфікації** | T4 — «Електровелосипед: знижка 20 % на погодинне нарахування за T3. Безкоштовних хвилин на електровелосипеді немає» (`docs/spec/tariffs.md:76-77`) |
| **Середовище** | дефект — у `main` (`4606c72`), відтворено на копії `git archive main app`; Node v26.3.0; Windows 10 (Git Bash) |
| **Серйозність** | висока — системний недобір: кожна поїздка абонента на електровелосипеді до 45 хв безкоштовна (замість 32–64 грн), довші — дешевші на 1–2 блоки; через вибір «вигіднішого плану» абонент із пільгою отримує абонемент 0 грн замість пільги (TC-29) |
| **Частота** | завжди для `rider.type = "subscriber"` і `bike = "ebike"` |
| **Знайдено** | `app/test/spec/tariff.test.js` › `T4: TC-22 …`, `T4: TC-23 абонент, електро 75 хв → 12000 − 20 % = 9600`, `T4: TC-59 …`, `T5: TC-29 …` (`ai-runs/b2-run.txt`) |
| **Виправлення** | `cf8cdfd fix(T4): e-bike subscription is 20% off with no free minutes` |

## Кроки відтворення

1. На коді з `main` порахувати поїздку електровелосипедом, абонент без права на пільгу,
   взяття `2026-09-16T07:00:00Z`, повернення `2026-09-16T07:40:00Z` (40 хв), S01.
2. Подивитися `timeCharge`, `discounts`, `total`.

## Очікуваний результат (за специфікацією)

40 хв → 2 блоки × 4000 = 8000 (T3, `:62`, `:67`); абонент на електро — −20 % (T4, `:76`):
знижка 1600 → до сплати **6400**. Безкоштовних хвилин немає (`:76-77`).

## Фактичний результат

`timeCharge: 8000`, `discounts: [{ code: "subscription", amount: 8000 }]`, `total: 0`.

## Доказ


## Мінімальний вхід

Абонент, електровелосипед, будь-яка поїздка понад 2 хв. Класичний велосипед або інша
категорія — дефект зникає.

## Додатково

- Місце в коді: `app/src/tariff.js:83-86` (`subscriptionCharge`) — 45 безкоштовних хвилин
  віднімалися для обох типів велосипеда, а −20 % для електро застосовувалося вже до
  залишку.
- Наявний тест `app/test/unit/tariff.test.js` › `subscribers ride the first 45 minutes free`
  перевіряв у циклі `classic` і `ebike` і стверджував дефект для електро; розділено на два
  тести за специфікацією (див. `docs/bugs/README.md`).
- Тест з коду `ai-runs/b1-from-code/tariff.test.js` › `subscriber e-bike gets an extra 20% off
  the paid part` (90 хв → 6400) стверджував дефект.
