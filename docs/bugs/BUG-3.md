## Кроки відтворення

1. Створити копію початкового коду: `mkdir -p ../ws12-main && git archive main app | tar -x -C ../ws12-main`.
2. Порахувати ebike-поїздку абонента від `2026-09-16T07:00:00Z` до `2026-09-16T07:30:00Z` зі станції повернення S03.

## Очікуваний результат (за специфікацією)

30 хв — один блок T3 вартістю 4000 коп. (`docs/spec/tariffs.md:62`, `:67`). Безкоштовних хвилин на ebike немає; 20% знижка становить 800 коп., отже до сплати 3200 коп. (`docs/spec/tariffs.md:76-77`).

## Фактичний результат

Початковий код застосовує безкоштовні 45 хв і повертає time charge 4000 коп., знижку 4000 коп. та total 0 коп.

## Мінімальний вхід

Один блок ebike (30 хв), абонент без пільги, повернення у зоні. Для classic безкоштовні перші 45 хв є правильними; це правило не переноситься на ebike.

## Додатково

Абонентська формула тепер віднімає 45 хв лише для classic; ebike отримує 20% знижки від повної погодинної суми. Старий unit-тест, що очікував безкоштовні 40 хв для ebike, оновлено окремим тестовим комітом `2b73dd0` за T4.
