# BUG-3: абонент на електровелосипеді не платить за перші 45 хвилин

| Поле | Значення |
|---|---|
| **Правило специфікації** | T4 — «Електровелосипед: знижка 20 % на погодинне нарахування за T3. Безкоштовних хвилин на електровелосипеді немає» (`docs/spec/tariffs.md:76`–`:77`) |
| **Середовище** | дефект — `main` `4606c72` (`app/src/` той самий до `b0066a1`); Node v24.16.0; Windows 11 Home 10.0.26200, Git Bash |
| **Серйозність** | висока — поїздка абонента на електровелосипеді недоплачена, якщо занижена сума не впирається в денний ліміт: до 45 хв — 0 замість 32 або 64 грн, довші — без перших 45 хв (75 хв: 32 грн замість 96 грн). Хибна сума знижки потрапляє в чек (TC-95: «-88,00 грн» замість «-24,00 грн») і в денний ліміт (TC-49); в абонента з пільгою через занижений абонемент обирається не той тариф (TC-39) |
| **Частота** | за умови: абонент на електровелосипеді, поїздка довша за 2 хв і занижена сума менша за залишок денного ліміту (інакше ліміт вирівнює суму, і різниця лише в рядку знижки: напр. 25 год — `total` 230000 в обох версіях); для абонента з пільгою — лише якщо занижений абонемент виявляється дешевшим за пільгу (600 хв — у обох версіях пільга, вивід однаковий) |
| **Знайдено** | `app/test/spec/t4-subscription.test.js` › `T4: TC-29 — ел., 30 хв → 1 блок − 20 % → 3200` (`ai-runs/b2-run.txt`); той самий дефект — TC-30, TC-31, TC-39, TC-49, TC-95 |
| **Виправлення** | `26d35b7` fix(T4): no free minutes for subscribers on e-bikes |

## Кроки відтворення

1. З кореня репо зробіть копію початкового коду (`main` = `4606c72`):
   `mkdir -p ../ws12-main && git archive main app | tar -x -C ../ws12-main`.
2. У `../ws12-main` порахуйте поїздку: електровелосипед, абонент, 16.09.2026 10:00:00 → 10:30:00
   за Києвом (`07:00:00Z` → `07:30:00Z`), повернення на S01 — команда в «Доказі».
3. Порівняйте знижку `subscription` і `total` з очікуваним.

## Очікуваний результат (за специфікацією)

30 хв — один блок (`:62`) по 40 грн (`:67`): `timeCharge` 4000. Абонемент на електровелосипеді —
лише знижка 20 % (`:76`–`:77`): знижка 800, **`total` = 3200** (32,00 грн).

## Фактичний результат

`discounts: [{ code: "subscription", amount: 4000 }]`, `total: 0` — перші 45 хв безкоштовні, як
для класичного велосипеда.

## Мінімальний вхід

Електровелосипед, абонент, S01, 30 хв. Дефект зникає, якщо взяти класичний велосипед (30 хв для
абонента — 0 в обох версіях, `:74`–`:75`) або стандартний тариф (4000 в обох версіях).

## Додатково

- Відтворено: кроки вище на копії `main` і в репо після виправлення (вивід наведено).
- Наявний тест `app/test/unit/tariff.test.js` › `subscribers ride the first 45 minutes free`
  стверджував 0 і для електровелосипеда; оновлено за специфікацією в тому самому
  коміті (`docs/bugs/README.md`).
- Тести з коду, що зафіксували дефект (`ai-runs/b1-rerun.txt`): `абонемент` › `електровелосипед:
  платні блоки зі знижкою 20 %` і `нічна знижка (…)` › `застосовується після абонемента` у
  `ai-runs/b1-from-code/tariff.test.js`.
- Місце в коді (рядки — на `main`): `app/src/tariff.js:83`–`:86` — `subscriptionCharge()` віднімала
  `SUBSCRIPTION_FREE_MINUTES` для будь-якого велосипеда; тепер 45 хв — лише для класичного, для
  електро — нарахування за T3 мінус 20 %.
