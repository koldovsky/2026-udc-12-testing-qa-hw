# BUG-3: Абонент на електровелосипеді отримує 45 безкоштовних хвилин

| Поле | Значення |
|---|---|
| **Правило специфікації** | T4 — «Електровелосипед: знижка 20 % на погодинне нарахування за T3. Безкоштовних хвилин на електровелосипеді немає» (`docs/spec/tariffs.md:76-77`) |
| **Середовище** | код з `main` (`4606c72`), Node v24.16.0, Windows 11 (Git Bash) |
| **Серйозність** | висока: кожна поїздка абонента на електро до 45 хв — безплатна (має коштувати від 3200 коп.), довші — занижені на 1–2 блоки; систематична втрата виручки на найдорожчому тарифі |
| **Частота** | завжди для абонента на електровелосипеді |
| **Знайдено** | `app/test/spec/discounts.test.js` › `T4: subscriber, e-bike, 60 min — 2 blocks = 8000 − 20 %, no free minutes → 6400 (TC-15)` (прогін `ai-runs/b2-run.txt`) |
| **Виправлення** | `2e3f871 fix(T4): на електровелосипеді в абонемента немає безкоштовних хвилин` |

## Кроки відтворення

1. Взяти код із `main` (`mkdir -p ../ws12-main && git archive main app | tar -x -C ../ws12-main`).
2. Порахувати вартість поїздки абонента на електровелосипеді 60 хв (команда нижче).

## Очікуваний результат (за специфікацією)

60 хв → 2 блоки × 4000 = 8000; знижка абонемента на електро — лише 20 % →
8000 × 0,8 = **6400 коп.** Безкоштовних хвилин немає (T4, `docs/spec/tariffs.md:76-77`).

## Фактичний результат

`total = 3200`: код спочатку відняв 45 «безкоштовних» хвилин (лишився 1 блок
= 4000), потім застосував −20 %. Поїздка 40 хв взагалі коштує 0.

## Доказ

```bash
cd ../ws12-main && node -e 'import("./app/src/tariff.js").then(({ quote }) => { const q = quote({ pickupAt: "2026-09-16T07:00:00Z", returnAt: "2026-09-16T08:00:00Z", bike: "ebike", returnStation: "S03" }, { type: "subscriber" }); console.log(JSON.stringify(q)); })'; cd -
```

```text
{"minutes":60,"timeCharge":8000,"discounts":[{"code":"subscription","amount":4800}],"fees":[],"total":3200}
```

Після виправлення — `discounts:[{"code":"subscription","amount":1600}]`, `total = 6400`.

## Мінімальний вхід

Абонент, електро, поїздка ≤ 45 хв (наприклад, 40 хв): на `main` → 0 коп.
замість 6400. Поміняйте велосипед на класичний — поведінка правильна (там
45 безкоштовних хвилин і належать).

## Додатково

Причина — `subscriptionCharge` віднімав `SUBSCRIPTION_FREE_MINUTES` для обох
типів велосипедів (`app/src/tariff.js:84` на `main`). Наявний тест
`app/test/unit/tariff.test.js` › «subscribers ride the first 45 minutes free»
стверджував 0 грн і для електро — оновлено за специфікацією в коміті
виправлення. Тест «з коду» `ai-runs/b1-from-code/tariff.test.js` ›
«абонемент, електро, 75 хв…» зафіксував дефект як норму (червоний у
`ai-runs/b1-rerun.txt`).
