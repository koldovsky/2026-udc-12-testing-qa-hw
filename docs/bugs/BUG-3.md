# BUG-3: Абонент на електровелосипеді отримує 45 безкоштовних хвилин: поїздка до 45 хв коштує 0 грн

| Поле | Значення |
|---|---|
| **Правило специфікації** | T4 — «**Електровелосипед:** знижка 20 % на погодинне нарахування за T3. Безкоштовних хвилин на електровелосипеді немає.» — `docs/spec/tariffs.md:76-77` (45 безкоштовних хвилин — лише для класичного, `:74-75`) |
| **Середовище** | Код до виправлення: `main` = `4606c72`, відтворено в копії `../ws12-main` (`git archive main app`). Виправлений код — коміт `d373a24` і новіші, перевірено на HEAD `b115710` (гілка `ws12/Fyfar`). Node `v26.0.0`, macOS `26.6.2` |
| **Серйозність** | **Критична.** Неправильно рахується кожна поїздка кожного абонента на електровелосипеді, а це найдорожчий тариф. До 45 хв включно поїздка коштує 0 грн замість 80 % від T3: 32 грн за 1 блок (4 000 − 20 % = 3 200 коп.) або 64 грн за 2 блоки (6 400 коп.). Довші поїздки втрачають 1–2 блоки: 75 хв — 32 грн замість 96 грн (`3200` проти `9600`). Обхідного шляху немає, втрата систематична. Абонентам із пільгою дефект ще й підміняє вибір тарифу T5 (TC-31) |
| **Частота** | Завжди, коли абонент (з правом на пільгу чи без) їде на електровелосипеді довше 2 хв (коротші поїздки безкоштовні за T2). До 45 хв — 0 грн. Понад 45 хв блоки відлічуються з 46-ї хвилини, як для класичного |
| **Знайдено** | `app/test/spec/t04-t05-subscription-reduced.test.js › T4: TC-23 абонент, електро, 30 хв — −20 %` (`ai-runs/b2-run.txt:30`, `4000 !== 800`); `… › T4: TC-24 абонент, електро, 45 хв — безкоштовних хвилин немає, −20 %` (`ai-runs/b2-run.txt:31`, `8000 !== 1600`); `… › T5 (+T7): TC-31 абонент з пільгою, електро, 30 хв, X03 — пільга, збір без знижки` (`ai-runs/b2-run.txt:37`) |
| **Виправлення** | `d373a24 fix(T4): на електровелосипеді абонент не має безкоштовних хвилин` |

## Кроки відтворення

1. У корені репо створіть копію початкового коду з `main`:
   `mkdir -p ../ws12-main && git archive main app | tar -x -C ../ws12-main`
2. Порахуйте в копії поїздку: абонент (без пільги), електровелосипед, взяття
   `2026-09-16T10:00:00+03:00`, повернення `2026-09-16T10:30:00+03:00` (30 хв), станція S01.
   Команда — у розділі «Доказ», варіант «до виправлення».
3. Подивіться на знижку `subscription` і `total`.
4. Для порівняння виконайте ту саму команду в корені репо (виправлений код).

## Очікуваний результат (за специфікацією)

30 хв → 1 блок × 40 грн = 4 000 коп. (T3, `docs/spec/tariffs.md:62-67`). Безкоштовних хвилин
немає, знижка 20 % (`:76-77`): 4 000 × 0,8 = 3 200 коп. Знижка `subscription` = **800 коп.**,
до сплати **3 200 коп. (32,00 грн)**.

## Фактичний результат

`"timeCharge": 4000`, знижка `{"code": "subscription", "amount": 4000}`, `"total": 0` —
**0,00 грн**: поїздку повністю списано як безкоштовні хвилини.

## Мінімальний вхід

Абонент, електровелосипед, S01, `10:00:00` → `10:30:00`. Якщо змінити велосипед на класичний,
0 грн — правильна сума (`:74-75`, приклад `:81`); на `main` це `30 min total 0`. Додаткові
перевірки тим самим викликом `quote` на `main` / після виправлення: електро, 45 хв — `total 0` /
`total 6400`; електро, 75 хв — `total 3200` / `total 9600`.

## Додатково

- **Тести зі специфікації**, які впали на `main`: TC-23, TC-24, TC-31 (див. «Знайдено»). У TC-31
  через дефект абонемент дає 0 грн погодинного, і це «дешевше» за пільгу (2 000 коп.). Тому
  застосовано `subscription`, а не `reduced`, як очікує T5 (`:89-91`). Після `d373a24` усі три
  зелені.
- **Тест «з коду», що закріпив дефект:** `ai-runs/b1-from-code/tariff.test.js › e-bike over the free
  period gets 20% off`. На `main` він зелений (`ai-runs/b1-run.txt:33`), після виправлення червоний
  (`ai-runs/b1-rerun.txt:33`).
- **Наявний unit-тест стверджував хибну поведінку:** `app/test/unit/tariff.test.js:37` (на `d373a24`) —
  «subscribers ride the first 45 minutes free» (для обох типів велосипеда 40 хв → 0). У коміті
  `d373a24` його перейменовано на «subscribers ride the first 45 minutes free on a classic bike only»:
  для електро 40 хв тепер очікується 6 400 коп. (2 блоки 8 000 − 20 %) за T4 (`:74-77`).
- **Місце в коді (гіпотезу підтвердив коміт виправлення):** `app/src/tariff.js:84` на `main` —
  `blocks(Math.max(0, minutes - SUBSCRIPTION_FREE_MINUTES))` для будь-якого велосипеда. У `d373a24`
  45 безкоштовних хвилин віднімаються лише для `classic` (тепер `app/src/tariff.js:82-83`).
