# BUG-3: абонент на електровелосипеді отримує 45 безкоштовних хвилин, яких не має

| Поле | Значення |
|---|---|
| **Правило специфікації** | T4 — «**Електровелосипед:** знижка 20 % на погодинне нарахування за T3. Безкоштовних хвилин на електровелосипеді немає.» (`docs/spec/tariffs.md:76-77`) |
| **Середовище** | До виправлення: `main`, коміт `4606c72`. Після: коміт `929ec5e`. Node v24.18.0, Windows 11 Home 10.0.26200, Git Bash |
| **Серйозність** | Висока: сума хибна на кожній платній поїздці абонента на електровелосипеді. Недоплата — наприклад, 64 грн за 45 хв і 32 грн за 46 хв |
| **Частота** | Завжди, якщо абонент їде на електровелосипеді довше за 2 хв |
| **Знайдено** | `app/test/spec/tariff.test.js` › `T4: TC-12 абонент на електровелосипеді: без безкоштовних хвилин, знижка 20 %` (`ai-runs/b2-run.txt:209`) |
| **Виправлення** | `1da69d6 fix(T4): без безкоштовних хвилин на електровелосипеді` |

## Кроки відтворення

1. Створіть копію початкового коду: `mkdir -p ../ws12-main && git archive main app | tar -x -C ../ws12-main`.
2. Розрахуйте поїздку абонента на електровелосипеді: взяття 16.09.2026 10:00:00, повернення
   10:45:00 за Києвом, станція S01.
3. Порівняйте `total` з очікуваним.

## Очікуваний результат (за специфікацією)

45 хв — це 2 розпочаті блоки по 40 грн (`docs/spec/tariffs.md:62,67`), тобто 8000 коп. Безкоштовних
хвилин немає, знижка 20 % (`:76-77`): 8000 × 0,8 = **6400 коп.**

## Фактичний результат

Знижка `subscription` дорівнює всьому нарахуванню, 8000 коп.: `total` 0 коп.

## Мінімальний вхід

Абонент, електровелосипед, взяття 10:00:00, повернення **10:03:00**. Результат на початковому коді
за інших умов (та сама команда, змінено лише вказане поле):

| Вхід | Початковий код | За специфікацією |
|---|---|---|
| абонент, електровелосипед, 3 хв | 0 | 4000 × 0,8 = 3200 |
| абонент, електровелосипед, 46 хв | 3200 | 2 блоки: 8000 × 0,8 = 6400 |
| абонент, електровелосипед, 2 хв (хибний старт) | 0 | 0 |
| абонент, класичний, 3 хв | 0 | 0 |
| стандартний, електровелосипед, 3 хв | 4000 | 4000 |

Дефект зникає, якщо змінити тип велосипеда або категорію користувача або якщо тривалість не більша
за 2 хв.
