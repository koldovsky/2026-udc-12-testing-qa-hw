# BUG-3: абонент на електровелосипеді отримує 45 безкоштовних хвилин, яких за T4 немає

| Поле | Значення |
|---|---|
| **Правило специфікації** | T4: «**Електровелосипед:** знижка 20 % на погодинне нарахування за T3. Безкоштовних хвилин на електровелосипеді немає.» — `docs/spec/tariffs.md:76-77`. Наслідок — вибір «пільга чи абонемент» за T5 (`:89-91`) |
| **Середовище** | Дефект: `main` = `4606c72` (код `app/src/` ідентичний `5468fe7`). Перевірка виправлення: `9623f08`. Node v22.14.0, macOS 26.4.1 |
| **Серйозність** | **Висока.** Зачіпає кожну поїздку абонента на електровелосипеді. Поїздки до 45 хв безкоштовні замість 32–64 грн, довші — дешевші на 1–2 блоки. Наприклад, 100 хв: 64 грн замість 128 грн. Систематична втрата доходу на найдорожчому тарифі. Абоненту з правом на пільгу через заниження суми абонемента обирається неправильний варіант T5 (TC-37: 32 грн замість 40 грн) |
| **Частота** | Завжди: кожна поїздка абонента на електровелосипеді тривалістю понад 2 хв |
| **Знайдено** | Прогін зі специфікації (`ai-runs/b2-run.txt`): `app/test/spec/t04-subscription.test.js` › `T4: TC-28 …`, `T4: TC-29 …`, `T4: TC-30 …`; `app/test/spec/t05-reduced.test.js` › `T5: TC-37 …` |
| **Виправлення** | `a8a219b fix(T4): no free minutes for subscribers on an e-bike` |

## Кроки відтворення

1. Взяти копію початкового коду: `mkdir -p ../ws12-main && git archive main app | tar -x -C ../ws12-main`.
2. Розрахувати дві поїздки абонента (`{ type: "subscriber" }`) на електровелосипеді, взяття
   16.09.2026 о 10:00 за Києвом, станція `S01`:
   - повернення о 10:30 (TC-28);
   - повернення об 11:40 (TC-30).
3. Запустити команду з розділу «Доказ» у `../ws12-main`, а потім у корені репо.

## Очікуваний результат (за специфікацією)

Безкоштовних хвилин немає, лише −20 % від T3 (`:76-77`):

- **30 хв:** 1 блок × 40 грн = 4 000 коп., × 0,8 = **3 200** (32 грн).
- **100 хв:** 4 блоки × 40 грн = 16 000 коп., × 0,8 = **12 800** (128 грн).

## Фактичний результат

- **30 хв:** знижка `subscription` 4 000, `total` **0**. Поїздка безкоштовна, бо 30 ≤ 45
  безкоштовних хвилин.
- **100 хв:** знижка 9 600, `total` **6400**. Рахуються лише 55 хв після 45 безкоштовних:
  2 блоки × 4 000 × 0,8.

## Мінімальний вхід

Абонент, **електровелосипед**, тривалість 3 хв, станція `S01`: код дає 0 замість 3 200.

- **Класичний велосипед:** дефект зникає (45 безкоштовних хвилин для нього правильні, `:74-75`).
- **Стандартний користувач:** дефект теж зникає, бо абонемента немає.

## Додатково

- **Місце в коді:** `app/src/tariff.js:83-86`, `subscriptionCharge()`. Функція віднімала
  `SUBSCRIPTION_FREE_MINUTES` для будь-якого велосипеда, а для `ebike` лише додавала −20 %.
  Виправлено в `a8a219b`: для електровелосипеда береться повна ціна T3 (`chargeFor`) з
  −20 %, без безкоштовних хвилин.
- **Наявний тест, що стверджував хибну поведінку:** `app/test/unit/tariff.test.js` ›
  `subscribers ride the first 45 minutes free` (0 і для `ebike`). Оновлено за T4 у тому
  самому коміті: класичний 0, електровелосипед 6 400 (див. `docs/bugs/README.md`).
- **Тести з коду, що зафіксували дефект:** `ai-runs/b1-from-code/tariff.test.js` ›
  `quote: subscription` › `e-bike blocks after the free time are 20 % off` і
  `an e-bike within 45 minutes is free`. Обидва зелені в `b1-run.txt`, червоні в
  `b1-rerun.txt`.
- **TC-37** (Аб+П · Ел · 60 хв) червонів через цей самий дефект, а не через логіку T5.
  Абонемент рахувався як 3 200 замість 6 400 і «вигравав» у пільги (4 000).
