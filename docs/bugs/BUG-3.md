# BUG-3: Абонементний e-bike помилково отримує безкоштовні хвилини

| Поле | Значення |
|---|---|
| **Правило специфікації** | **T4:** для classic «перші 45 хвилин ... безкоштовні» (`docs/spec/tariffs.md:72-75`); для ebike «знижка 20 % на погодинне нарахування за T3. Безкоштовних хвилин ... немає» (`docs/spec/tariffs.md:74-77`). |
| **Середовище** | Початковий код: `main` (`4606c72`), Node `v22.23.2`, Windows. Виправлений код перевірено після `ddd6f1b`. |
| **Серйозність** | Висока: абоненти на e-bike систематично недоплачували; для 75 хв різниця становила 6400 коп. |
| **Частота** | Завжди для subscriber з `bike: "ebike"` і тривалістю понад 45 хв; також неправильний результат є для коротших поїздок. |
| **Знайдено** | `app/test/spec/tariffs.test.js` › `T4: TC-09`; початковий B2-прогін. |
| **Виправлення** | `ddd6f1b fix(T4): correct subscriber ebike discount` — для ebike береться повна T3-сума і віднімається 20%, без віднімання 45 хв; unit-тест розділено для classic та ebike. |

## Кроки відтворення

1. Перейти до кореня репозиторію або окремої копії `main`.
2. Виконати команду з розділу «Доказ».

## Очікуваний результат (за специфікацією)

75 хв classic = 3 блоки по 2500 коп. Для ebike 75 хв = 3 блоки по 4000 коп. = 12000 коп.; subscriber отримує 20% знижки, 2400 коп., тому `total = 9600` коп. Безкоштовні 45 хв для ebike не застосовуються.

## Фактичний результат

На `main` функція повертала `timeCharge: 12000`, але discount `8800` і `total: 3200`, фактично застосовуючи 45 безкоштовних хвилин і 20% до залишку. Після `ddd6f1b` повертає discount `2400` і `total: 9600`.

## Доказ

```bash
node -e "import('./app/src/tariff.js').then(({quote}) => console.log(JSON.stringify(quote({pickupAt:'2026-09-16T10:00:00Z',returnAt:'2026-09-16T11:15:00Z',bike:'ebike',returnStation:'S01'},{type:'subscriber'}))))"
```

На копії `main`:

```text
{"minutes":75,"timeCharge":12000,"discounts":[{"code":"subscription","amount":8800}],"fees":[],"total":3200}
```

Після `ddd6f1b`:

```text
{"minutes":75,"timeCharge":12000,"discounts":[{"code":"subscription","amount":2400}],"fees":[],"total":9600}
```

## Мінімальний вхід

E-bike, subscriber, `S01`, інтервал `10:00:00`—`11:15:00` UTC. Для додаткової перевірки меж після виправлення: 30 хв → 3200 коп., 45 хв → 6400 коп.; classic 45 хв → 0 коп.

## Додатково

Початкова логіка була в `app/src/tariff.js`, `subscriptionCharge()`: для всіх bike спочатку віднімалися `SUBSCRIPTION_FREE_MINUTES`, а потім для ebike застосовувалася знижка. Це суперечило T4. Коміт `ddd6f1b` підтверджено Git-історією; він змінює реалізацію і unit-тест `subscribers ride the first 45 minutes free`.
