# BUG-2: поїздка рівно 2 хвилини оплачується як повний блок

| Поле | Значення |
|---|---|
| **Правило специфікації** | T2 — «Поїздка тривалістю не більше 2 хвилин (за T1) — без погодинного нарахування.» `docs/spec/tariffs.md:54` |
| **Середовище** | `main` = `4606c72` (до виправлення, копія `../ws12-main`); після — коміт виправлення; Node v22.22.3; macOS (Darwin 25.6.0) |
| **Серйозність** | середня — користувач переплачує 25 грн (класичний) або 40 грн (електро) за хибний старт; поширений сценарій (велосипед несправний — одразу повернули) |
| **Частота** | завжди, коли тривалість за T1 = 2 хв (1 хв 0,001 с … 2 хв 0 с після виправлення BUG-1) |
| **Знайдено** | `app/test/spec/t1-t3-duration-blocks.test.js` › `T2: TC-07 classic, 10:00:00 → 10:02:00 → 2 хв, 0`, `T1: TC-05 classic, 10:00:00 → 10:01:30 → 2 хв, 0` (`ai-runs/b2-run.txt`) |
| **Виправлення** | `cd715b4 fix(T2): no time charge for rides of up to 2 minutes inclusive` |

## Кроки відтворення

1. Стандартний користувач, класичний велосипед, станція `S01`.
2. Взяття `2026-09-16T07:00:00Z`, повернення `2026-09-16T07:02:00Z` (рівно 2 хв).
3. Викликати `quote()`.

## Очікуваний результат (за специфікацією)

2 хв — «не більше 2 хвилин» → погодинне нарахування **0** (`:54`) → **`total: 0`**.

## Фактичний результат

`timeCharge: 2500`, `total: 2500`.

## Доказ

```bash
node -e 'import("./app/src/tariff.js").then(({ quote }) => console.log(JSON.stringify(quote({ pickupAt: "2026-09-16T07:00:00Z", returnAt: "2026-09-16T07:02:00Z", bike: "classic", returnStation: "S01" }, { type: "standard" }))))'
```

До виправлення (`cd ../ws12-main && <та сама команда>`, код з `main`):

```text
{"minutes":2,"timeCharge":2500,"discounts":[],"fees":[],"total":2500}
```

Після виправлення (у репо):

```text
{"minutes":2,"timeCharge":0,"discounts":[],"fees":[],"total":0}
```

## Мінімальний вхід

Рівно 2 хв. Повернення `07:01:00Z` (1 хв) — дефект зникає.

## Додатково

Гіпотеза: `app/src/tariff.js:79` — `minutes < FREE_START_MINUTES` замість `<=`. Тест з коду `ai-runs/b1-from-code/tariff.test.js` › `2 minutes is one block` зафіксував дефект.
