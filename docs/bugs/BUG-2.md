# BUG-2: Поїздка рівно на 2 хвилини тарифікується замість безкоштовного хибного старту

| Поле | Значення |
|---|---|
| **Правило специфікації** | T2 — «Поїздка тривалістю не більше 2 хвилин (за T1) — без погодинного нарахування.» (`docs/spec/tariffs.md:54`) |
| **Середовище** | `main` (початковий код) і коміт `3033521` (після виправлення); Node v26.13.0; Darwin 25.6.0 |
| **Серйозність** | середня — користувач платить 25 грн (класичний) або 40 грн (електро) за поїздку, яка за правилом безкоштовна; зачіпає лише поїздки тривалістю рівно 2 хв |
| **Частота** | завжди для тривалості рівно 2 хв (після виправлення T1 — для 1 с…2 хв 0 с) |
| **Знайдено** | `app/test/spec/duration-and-time-charge.test.js` › `T2: TC-07 exactly 2 min is free`, `T2: TC-10 e-bike, 2 min is free` (`ai-runs/b2-run.txt`) |
| **Виправлення** | коміт `3033521` (`git log --oneline -1 3033521`) |

## Кроки відтворення

1. З кореня репо виконати команду з розділу «Доказ» — на копії початкового коду з `main` (`mkdir -p ../ws12-main && git archive main app | tar -x -C ../ws12-main && cd ../ws12-main`).
2. Порівняти вивід з очікуваним.
3. Виконати ту саму команду в репо після виправлення (`3033521`) — вивід збігається з очікуваним.

## Очікуваний результат (за специфікацією)

тривалість 2 хв → без погодинного нарахування → 0 коп (`docs/spec/tariffs.md:54`).

## Фактичний результат

`minutes: 2`, `timeCharge: 2500`, `total: 2500`: умова хибного старту `minutes < 2` замість `<= 2`.

## Доказ

```bash
node -e 'import("./app/src/tariff.js").then(({ quote }) => console.log(JSON.stringify(quote(
  { pickupAt: "2026-09-16T07:00:00Z", returnAt: "2026-09-16T07:02:00Z", bike: "classic", returnStation: "S01" },
  { type: "standard" }))))'
```

До виправлення (початковий код з `main`):

```text
{"minutes":2,"timeCharge":2500,"discounts":[],"fees":[],"total":2500}
```

Після виправлення (`3033521`):

```text
{"minutes":2,"timeCharge":0,"discounts":[],"fees":[],"total":0}
```

## Мінімальний вхід

взяття 07:00:00Z, повернення 07:02:00Z, класичний; на 07:01:00Z — правильно (0).

## Додатково

Тест з коду, що стверджував хибну поведінку: `ai-runs/b1-from-code/tariff.test.js` › `2 minutes costs one block` (почервонів після виправлення). Гіпотеза: `app/src/tariff.js:79`, `<` → `<=`.
