1. З кореня репо в Git Bash викликати `quote` для стандартного користувача, класичний

2. Подивитися на `timeCharge` і `total`.

## Очікуваний результат (за специфікацією)

Тривалість 2 хв — «не більше 2 хвилин» (`docs/spec/tariffs.md:54`) → погодинного
нарахування немає: `timeCharge` = 0, зборів немає (станція в зоні) → `total` = **0**.

## Фактичний результат
