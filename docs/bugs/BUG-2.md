# BUG-2: поїздку рівно 2 хвилини оплачують, хоча це ще хибний старт

| Поле | Значення |
|---|---|
| **Правило специфікації** | T2 — «Поїздка тривалістю не більше 2 хвилин (за T1) — без погодинного нарахування.» — `docs/spec/tariffs.md:54` |
| **Середовище** | коміт до виправлення: `148b125`; Node v26.3.0; Windows 11 Pro 10.0.26300 |
| **Серйозність** | середня — користувач, який одразу повернув велосипед (рівно 2 хв), переплачує 25 грн (класичний) або 40 грн (електровелосипед) за поїздку, якої фактично не було |
| **Частота** | завжди, коли тривалість за T1 дорівнює рівно 2 хв |
| **Знайдено** | `app/test/spec/t1-t3-duration-blocks.test.js` › `T1, T2: TC-05 …`, `T2: TC-07 …` (`ai-runs/b2-run.txt:19`, `:21`) |
| **Виправлення** | `dfe41dc fix(T2): no time charge for a ride of exactly 2 minutes` |

## Кроки відтворення

1. Порахувати стандартну поїздку на класичному велосипеді: взяття `2026-09-16T07:00:00Z`,
   повернення `2026-09-16T07:02:00Z` (рівно 2 хв 00 с), станція S01.
2. Подивитися `minutes` і `total`.

## Очікуваний результат (за специфікацією)

2 хв — «не більше 2 хвилин» (`:54`) → погодинного нарахування немає, зборів немає →
**0 коп.**

## Фактичний результат

`minutes 2`, `total 2500` — нараховано 1 блок.

## Доказ

```bash
node -e "import('./app/src/tariff.js').then(({quote})=>{const q=quote({pickupAt:'2026-09-16T07:00:00Z',returnAt:'2026-09-16T07:02:00Z',bike:'classic',returnStation:'S01'},{type:'standard'});console.log(q.minutes,q.total)})"
```

```text
2 2500
```

## Мінімальний вхід

Рівно 2 хв 00 с. За 1 хв (наприклад 50 с, TC-06) — 0, як і має бути; за 3 хв — 1 блок, як і
має бути. Хибна лише межа «рівно 2».

## Додатково

- Гіпотеза: `app/src/tariff.js:79` — `if (minutes < FREE_START_MINUTES) return 0;` — строга
  нерівність замість «не більше» (`<=`).
- Разом із BUG-1 зсувається ще й 2 хв 1 с … 2 хв 29 с (рахуються як 2 хв). Після виправлення
  BUG-1 це 3 хв → 1 блок, як і за специфікацією (TC-08).
- Тест з коду `ai-runs/b1-from-code/tariff.test.js` › `from 2 minutes the first 30-minute block
  is charged in full` стверджує саму хибну поведінку (крок 5).
