# BUG-2: Поїздка рівно 2 хвилини — платна, хоча це хибний старт

| Поле | Значення |
|---|---|
| **Правило специфікації** | T2 — «Поїздка тривалістю не більше 2 хвилин (за T1) — без погодинного нарахування» (`docs/spec/tariffs.md:54`) |
| **Серйозність** | висока: з користувача стягують 25/40 грн за хибний старт, який специфікація гарантує безплатним; прямі скарги і повернення коштів |
| **Середовище** | код з `main` (`4606c72`), Node v24.16.0, Windows 11 (Git Bash) |
| **Частота** | завжди для тривалості рівно 2 хв (після T1-округлення — будь-яка поїздка 1:01–2:00) |
| **Знайдено** | `app/test/spec/time-charge.test.js` › `T2: exactly 2 min 00 s is "not more than 2 minutes" → 0 (TC-05)` (прогін `ai-runs/b2-run.txt`) |
| **Виправлення** | `4a9f549 fix(T2): поїздка рівно 2 хвилини — хибний старт без нарахування` |

## Кроки відтворення

1. Взяти код із `main` (`mkdir -p ../ws12-main && git archive main app | tar -x -C ../ws12-main`).
2. Порахувати вартість поїздки класичним велосипедом рівно 2 хв (команда нижче).

## Очікуваний результат (за специфікацією)

2 хв — «не більше 2 хвилин» → погодинне нарахування **0**, разом **0 коп.**
(T2, `docs/spec/tariffs.md:54`).

## Фактичний результат

`timeCharge = 2500`, `total = 2500` — нараховано повний блок.

## Доказ

```bash
cd ../ws12-main && node -e 'import("./app/src/tariff.js").then(({ quote }) => { const q = quote({ pickupAt: "2026-09-16T07:00:00Z", returnAt: "2026-09-16T07:02:00Z", bike: "classic", returnStation: "S03" }, { type: "standard" }); console.log(JSON.stringify({ minutes: q.minutes, timeCharge: q.timeCharge, total: q.total })); })'; cd -
```

```text
{"minutes":2,"timeCharge":2500,"total":2500}
```

Після виправлення — `{"minutes":2,"timeCharge":0,"total":0}`.

## Мінімальний вхід

Поїздка рівно 2:00. На 1 хв — дефекту не видно (безплатно і до виправлення),
на 2:01 (→ 3 хв за T1) — платно правомірно.

## Додатково

Причина — строге порівняння `minutes < FREE_START_MINUTES` замість `<=`
(`app/src/tariff.js:79` на `main`). Тест «з коду»
`ai-runs/b1-from-code/tariff.test.js` › «рівно 2 хв — уже платно, один блок»
зафіксував дефект як норму (червоний у `ai-runs/b1-rerun.txt`).
