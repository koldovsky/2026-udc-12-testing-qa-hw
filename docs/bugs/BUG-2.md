# BUG-2: поїздку рівно 2 хвилини рахують як платну, хоча це хибний старт

| Поле | Значення |
|---|---|
| **Правило специфікації** | T2 — «Поїздка тривалістю не більше 2 хвилин (за T1) — без погодинного нарахування» (`docs/spec/tariffs.md:54`) |
| **Середовище** | дефект — у `main` (`4606c72`), відтворено на копії `git archive main app`; Node v26.3.0; Windows 10 (Git Bash) |
| **Серйозність** | середня — користувач, який повернув велосипед за 2 хв (типовий хибний старт: заїло замок, не той велосипед), платить 25 грн (класичний) або 40 грн (електро) замість 0 |
| **Частота** | завжди, коли тривалість за T1 рівно 2 хв (`minutes < 2` замість `<= 2`) |
| **Знайдено** | `app/test/spec/tariff.test.js` › `T2: TC-08 рівно 2 хв → 0` (`ai-runs/b2-run.txt`) |
| **Виправлення** | `4dec1f1 fix(T2): no time charge for a ride of exactly 2 minutes` |

## Кроки відтворення

1. На коді з `main` порахувати поїздку класичним велосипедом, стандартний користувач,
   взяття `2026-09-16T07:00:00Z`, повернення `2026-09-16T07:02:00Z`, S01.
2. Подивитися `timeCharge` і `total`.

## Очікуваний результат (за специфікацією)

2 хв ≤ 2 хв → хибний старт → погодинне нарахування **0**, до сплати **0** (T2, `:54`).

## Фактичний результат

`minutes: 2`, `timeCharge: 2500`, `total: 2500`.
