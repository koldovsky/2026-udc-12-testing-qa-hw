# BUG-2: поїздку рівно 2 хвилини оплачують, хоча до 2 хвилин включно вона без плати за час

| Поле | Значення |
|---|---|
| **Правило специфікації** | T2 — «Поїздка тривалістю не більше 2 хвилин (за T1) — без погодинного нарахування» (`docs/spec/tariffs.md:54`) |
| **Середовище** | дефект — `main` `4606c72` (`app/src/` той самий до `b0066a1`); Node v24.16.0; Windows 11 Home 10.0.26200, Git Bash |
| **Серйозність** | середня — користувач платить за поїздку, яка за правилом без погодинного нарахування, — типовий хибний старт (велосипед не підійшов і його одразу повернули). Переплата — нарахування за 1 блок після знижок поїздки: 25 / 40 грн (класичний / електро) за стандартним тарифом, 12,50 / 20 грн за пільгою; уночі за стандартним тарифом — на 30 % менше (17,50 / 28 грн). Абонентів (зокрема з пільгою) не зачіпає: їхнє нарахування за 2 хв і так 0. Сума невелика, але це переплата користувача й привід для скарги; у пільговика разом із BUG-4 ще й зменшувався збір (TC-16) |
| **Частота** | за умови: тривалість за T1 рівно 2 хв (поїздка понад 1 хв і не довша за 2 хв, зокрема з частками секунди), стандартний або пільговий тариф і денний ліміт ще не вичерпано (якщо вичерпано, нарахування поглинає рядок ліміту — до сплати 0 в обох версіях; якщо залишок менший за блок, переплата дорівнює залишку); на коді з `main`, де ще є BUG-1, — для поїздок від 1 хв 30 с до 2 хв включно |
| **Знайдено** | `app/test/spec/t2-false-start.test.js` › `T2: TC-10 — межа 2:00 — «не більше 2 хвилин» → 0` (`ai-runs/b2-run.txt`); той самий дефект — TC-09, TC-14, TC-15, TC-16 |
| **Виправлення** | `a09332c` fix(T2): no time charge for rides of up to 2 minutes inclusive |

## Кроки відтворення

1. З кореня репо зробіть копію початкового коду (`main` = `4606c72`):
   `mkdir -p ../ws12-main && git archive main app | tar -x -C ../ws12-main`.
2. У `../ws12-main` порахуйте поїздку: класичний велосипед, стандартний тариф, 16.09.2026
   10:00:00 → 10:02:00 за Києвом (`07:00:00Z` → `07:02:00Z`), повернення на S01 — команда в
   «Доказі».
3. Порівняйте `timeCharge` і `total` з очікуваним.

## Очікуваний результат (за специфікацією)

Тривалість рівно 2 хв (`:45`–`:47`) — «не більше 2 хвилин», тому погодинного нарахування немає
(`:54`): `timeCharge` і `total` = **0**. Зборів немає (S01 у зоні, `:166`–`:176`).

## Фактичний результат

`minutes: 2`, `timeCharge: 2500`, `total: 2500` — нараховано один блок (25,00 грн).

## Мінімальний вхід

Класичний, стандартний, S01, **рівно 2 хв** (`07:00:00Z` → `07:02:00Z`). Дефект зникає, якщо
тривалість 1 хв (`07:01:00Z` → 0 в обох версіях) або рівно 3 хв (`07:03:00Z` → 3 хв → 2500 в обох
версіях): помилка рівно на межі «не більше 2». Абонент на тій самій поїздці платить 0 в обох
версіях.
