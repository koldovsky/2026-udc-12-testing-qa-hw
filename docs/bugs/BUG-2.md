# BUG-2: За поїздку рівно 2 хв знімають плату за блок, хоча це хибний старт

| Поле | Значення |
|---|---|
| **Правило специфікації** | T2 — «Поїздка тривалістю не більше 2 хвилин (за T1) — без погодинного нарахування.» — `docs/spec/tariffs.md:54` |
| **Середовище** | Код до виправлення: `main` = `4606c72`, відтворено в копії `../ws12-main` (`git archive main app`). Виправлений код — коміт `fb84387` і новіші, перевірено на HEAD `b115710` (гілка `ws12/Fyfar`). Node `v26.0.0`, macOS `26.6.2` |
| **Серйозність** | **Середня.** Користувач переплачує: 25 грн (класичний) або 40 грн (електро) за поїздку, яка за правилом безкоштовна; зі знижками сума менша, але теж не 0. T2 захищає саме того, хто взяв велосипед і одразу його повернув (наприклад, несправний), тож кожен такий випадок — це скарга й повернення коштів. Вікно вузьке, тому серйозність невисока |
| **Частота** | Завжди, коли тривалість за T1 дорівнює рівно 2 хв. На виправленому T1 (`Math.ceil`) це фактичний час від 1 хв 0,001 с до 2 хв 0 с включно. На `main` (разом із BUG-1) зайво оплачуються поїздки від 1 хв 30 с до 2 хв 0 с: 1 хв 30 с → `2 min total 2500` на `main` проти `2 min total 0` після виправлень |
| **Знайдено** | `app/test/spec/t01-t02-duration.test.js › T2: TC-07 рівно 2 хв — хибний старт, 0` (`ai-runs/b2-run.txt:14`, `2500 !== 0`) |
| **Виправлення** | `fb84387 fix(T2): поїздка рівно 2 хв — хибний старт` |

## Кроки відтворення

1. У корені репо створіть копію початкового коду з `main`:
   `mkdir -p ../ws12-main && git archive main app | tar -x -C ../ws12-main`
2. Порахуйте в копії поїздку: стандартний користувач, класичний велосипед, взяття
   `2026-09-16T10:00:00+03:00`, повернення `2026-09-16T10:02:00+03:00` (рівно 2 хв), станція S01.
   Команда — у розділі «Доказ», варіант «до виправлення».
3. Подивіться на `minutes`, `timeCharge` і `total`.
4. Для порівняння виконайте ту саму команду в корені репо (виправлений код).

## Очікуваний результат (за специфікацією)

Тривалість 2 хв 0 с → **2 хв** (T1, `docs/spec/tariffs.md:46-47`). Це «не більше 2 хвилин», тому
погодинного нарахування немає (`:54`): **0 грн**. Повернення на S01 (у зоні, додаток А `:166`), отже
зборів немає. До сплати **0 коп.**

## Фактичний результат

`"minutes": 2`, `"timeCharge": 2500`, `"total": 2500` — **25,00 грн**, нараховано 1 блок.

## Мінімальний вхід

Стандартний користувач, класичний велосипед, S01, `10:00:00` → `10:02:00`. Якщо зменшити поїздку
так, щоб вона рахувалася як 1 хв (на `main` це `10:00:00` → `10:01:29` → `1 min total 0`), дефект
зникає. Якщо збільшити до `10:02:01` (3 хв за T1), 1 блок — правильна плата (TC-08).
