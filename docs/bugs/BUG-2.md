# BUG-2: Рівно дві хвилини помилково тарифікуються

| Поле | Значення |
|---|---|
| **Правило специфікації** | **T2:** «Поїздка тривалістю не більше 2 хвилин (за T1) — без погодинного нарахування» (`docs/spec/tariffs.md:52-58`). |
| **Середовище** | Початковий код: `main` (`4606c72`), Node `v22.23.2`, Windows. Виправлений код перевірено після `1197440`. |
| **Серйозність** | Висока: кожну поїздку рівно на 2 хвилини було помилково оплачено одним блоком — 2500 коп. для classic або 4000 коп. для ebike. |
| **Частота** | Завжди для поїздок, які після T1 мають рівно 2 хвилини. |
| **Знайдено** | `app/test/spec/tariffs.test.js` › `T2: TC-03`; початковий B2-прогін. |
| **Виправлення** | `1197440 fix(T2): include two-minute rides in free start` — умову `minutes < FREE_START_MINUTES` замінено на `minutes <= FREE_START_MINUTES`. |

## Кроки відтворення

1. Перейти до кореня репозиторію або окремої копії `main`.
2. Виконати команду з розділу «Доказ».

## Очікуваний результат (за специфікацією)

Для classic-поїздки тривалістю рівно 2 хвилини очікуються `minutes: 2`, `timeCharge: 0`, порожні `discounts` і `fees`, `total: 0`.

## Фактичний результат

На `main` функція повертала `minutes: 2`, але `timeCharge: 2500` і `total: 2500`. Після `1197440` повертає `timeCharge: 0` і `total: 0`.

## Доказ

```bash
node -e "import('./app/src/tariff.js').then(({quote}) => console.log(JSON.stringify(quote({pickupAt:'2026-09-16T10:00:00Z',returnAt:'2026-09-16T10:02:00Z',bike:'classic',returnStation:'S01'},{type:'standard'}))))"
```

На копії `main`:

```text
{"minutes":2,"timeCharge":2500,"discounts":[],"fees":[],"total":2500}
```

Після `1197440`:

```text
{"minutes":2,"timeCharge":0,"discounts":[],"fees":[],"total":0}
```

## Мінімальний вхід

Classic, стандартний rider, `S01`, інтервал `10:00:00`—`10:02:00` UTC. 1 хв також безкоштовна; 2 хв 1 с після T1 стає 3 хв і вже тарифікується одним блоком.

## Додатково

Початкова логіка була в `app/src/tariff.js`, `chargeFor()`: `if (minutes < FREE_START_MINUTES) return 0`. Початковий unit-тест на межі також очікував оплату рівно за 2 хв, але це було застаріле очікування; у поточному звіті він не змінювався в межах цього дефекту. Коміт `1197440` підтверджено Git-історією.
