## Мінімальний вхід

Стандартний користувач, класичний велосипед, взяття 10:00:00, повернення **10:02:00**. Результат
на початковому коді за іншого моменту повернення (та сама команда, змінено лише `returnAt`):

| Повернення | Початковий код | За специфікацією |
|---|---|---|
| 10:01:00 | 1 хв, 0 | 1 хв, 0 |
| 10:01:30 | 2 хв, 2500 | 2 хв, 0 |
| 10:02:00 | 2 хв, 2500 | 2 хв, 0 |
| 10:03:00 | 3 хв, 2500 | 3 хв, 2500 |

Дефект зникає, якщо тривалість не дорівнює 2 хв.
