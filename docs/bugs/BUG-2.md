## Кроки відтворення

1. Із кореня репо створити копію початкового коду: `mkdir -p ../ws12-main`; `git archive main app | tar -x -C ../ws12-main`.
2. У корені `../ws12-main` виконати команду з розділу «Доказ». Для звіту копія була в `/private/tmp/ws12-main`.

## Очікуваний результат (за специфікацією)

Рівно 2 хв входять до T2: `minutes=2`, `timeCharge=0`, `total=0` для повернення у зоні (`docs/spec/tariffs.md:54-58`).

## Фактичний результат до виправлення

`minutes=2`, `timeCharge=2500`, `total=2500`. Початковий `app/src/tariff.js:78-80` використовував умову `minutes < 2` замість `<= 2`.

## Доказ

Команда з кореня копії `main`:

```bash
node --input-type=module -e 'import { quote } from "./app/src/tariff.js"; const r=quote({pickupAt:"2026-09-16T10:00:00+03:00",returnAt:"2026-09-16T10:02:00+03:00",bike:"classic",returnStation:"S02"},{type:"standard"}); console.log(JSON.stringify({minutes:r.minutes,timeCharge:r.timeCharge,total:r.total}));'
```

```text
{"minutes":2,"timeCharge":2500,"total":2500}
```

На виправленому коді: `{"minutes":2,"timeCharge":0,"total":0}`. `ai-runs/b2-run.txt` (TC-04) показує той самий розрив, а TC-24 — зайві 2500 коп. навіть при законному зборі T7.

## Мінімальний вхід

Стандартний користувач, класичний велосипед, станція S02, рівно 2 хв. За 1 хв помилки немає; після 2 хв T3 уже діє.

## Додатково

Наявні unit-тести не фіксували рівно 2 хв. Виправлення не змінює збір T7 за таку поїздку (`docs/spec/tariffs.md:54-55`).
