# BUG-2: Хибний старт 2 хвилини тарифікується замість безкоштовного

| Поле | Значення |
|---|---|
| **Правило специфікації** | T2 — «Поїздка тривалістю не більше 2 хвилин (за T1) — без погодинного нарахування.» `docs/spec/tariffs.md:54` |
| **Середовище** | `c55b738`, Node v25.3.0, Darwin 25.6.0 |
| **Серйозність** | висока — користувач платить за поїздку, яка має бути безкоштовною; зачіпає кожен хибний старт рівно 2 хв |
| **Частота** | завжди, коли тривалість = 2 хв |
| **Знайдено** | `app/test/spec/tariff.test.js` › `T2: exactly 2 min → free (≤2)` та `ai-runs/b2-run.txt:16` |
| **Виправлення** | `c55b738 fix(T2): false start threshold should include 2 minutes` |

## Кроки відтворення

1. Викликати `quote()` з поїздкою тривалістю рівно 2 хв (pickup 07:00:00, return 07:02:00).
2. Подивитися `timeCharge` у результаті.

## Очікуваний результат (за специфікацією)

`timeCharge = 0` — за T2 (`docs/spec/tariffs.md:54`) «не більше 2 хвилин» включає 2 хвилини.

## Фактичний результат

`timeCharge = 2500` — код перевіряв `minutes < FREE_START_MINUTES` (2), тобто лише < 2, а не ≤ 2.

## Доказ

```bash
node -e 'import("../ws12-main/app/src/tariff.js").then(({ quote }) => console.log(JSON.stringify(quote({ pickupAt: "2026-09-16T07:00:00Z", returnAt: "2026-09-16T07:02:00Z", bike: "classic", returnStation: "S01" }, { type: "standard" }))))'
```

## Мінімальний вхід

Поїздка рівно 2 хв. При 1 хв — безкоштовно (обидва випадки збігаються). При 3 хв — правильно тарифікується. Тільки рівно 2 хв оголює баг.

## Додатково

Рядок `app/src/tariff.js:77`: було `minutes < FREE_START_MINUTES`, виправлено на `minutes <= FREE_START_MINUTES`. Тест B2 `T2: 2 min 1 sec → 3 min (ceil)` теж падав через каскадний ефект BUG-1 (округлення Math.round давало 2 хв замість 3).
