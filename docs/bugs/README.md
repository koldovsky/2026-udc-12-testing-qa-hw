# Червоні тести і дефекти

Прогони, які класифікуються: `ai-runs/b1-run.txt` (тести, написані **з коду**, на
невиправленому коді) і `ai-runs/b2-run.txt` (тести, написані **зі специфікації**, теж на
невиправленому коді). Класифікацію й виправлення підписую я: Liudmyla Minenkova, 2026-11-07.

**Головний результат прогону «з коду»: червоних тестів у ньому немає — 98 з 98 зелені**
(`ai-runs/b1-run.txt`, рядки `# pass 98` / `# fail 0`). Тести, написані з коду, не знайшли
жодного з п'яти дефектів: вони описували поточну поведінку, тому були зелені саме тому, що
код неправильний. Рівно ці 98 тестів, **без жодної правки**, на виправленому коді дають
12 червоних (`ai-runs/b1-rerun.txt`) — див. розділ «Тести з коду після виправлення».
