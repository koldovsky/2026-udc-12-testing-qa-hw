## Нестабільний тест

`app/test/integration/receipt.test.js` › `every receipt of a week of rides ends with the amount due`
**червоніє то так, то ні без змін у коді.** Ним займемося в Task D; до того часу тест не
змінюємо.

- **Частота:** `npm run test:repeat -- 30` → `6/30`. Інші 9 червоних тестів у тому самому прогоні
  падають `30/30`.
- **Приклади виводу:** `classic, 30 min … got "… 25,00 грн", expected 50,00 грн`;
  `classic, 60 min … got "… 50,00 грн", expected 75,00 грн`.
- **Причина:** помилка в очікуванні самого тесту (`receipt.test.js:15`), а не в коді. Перебір
  усіх значень, які може видати `test/helpers/factory.js` (обидва типи велосипеда, усі моменти
  взяття, 5–89 хв; 102 170 комбінацій), показав, що тест падає лише на **30 і 60 хв**.
- **Чому нестабільний:** тривалість випадкова (`factory.js:15`), у тесті 10 поїздок.
  Імовірність хоча б раз отримати 30 або 60 хв: 1 − (83/85)¹⁰ ≈ 21 %, що узгоджується з 6/30.
- **Код на цьому вході правильний:**
  `quote({ pickupAt: "2026-09-21T07:29:00Z", returnAt: "2026-09-21T08:29:00Z", bike: "classic", returnStation: "S01" }, { type: "standard" })`
  → `"minutes":60,"timeCharge":5000,"total":5000`, тобто 2 блоки за `tariffs.md:62,66`.
