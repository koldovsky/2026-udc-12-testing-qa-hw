# BUG-1: Поїздка 30 хв 20 с коштує як 30 хв — другий блок не відкривається

| Поле | Значення |
|---|---|
| **Правило специфікації** | T1 — «Неповна хвилина рахується як повна: тривалість округлюється вгору до цілих хвилин» (`docs/spec/tariffs.md:46-47`) |
| **Середовище** | код з `main` (`4606c72`), Node v24.16.0, Windows 11 (Git Bash) |
| **Серйозність** | висока: на кожній межі блоку (30/60/90 хв…) сервіс недоотримує цілий блок (25/40 грн), якщо «хвіст» поїздки — до 30 с; а на межі T8 губиться збір за неповернений велосипед: поїздка 24 год 0 хв 20 с рахується як 1440 хв, і збір 2 000 грн не нараховується (300 грн замість 2 300 грн, див. «Додатково») |
| **Частота** | завжди, коли неповна хвилина має «хвіст» < 30 с (Math.round округлює вниз) |
| **Знайдено** | `app/test/spec/time-charge.test.js` › `T1: a partial minute rounds up: 10:00:00–10:30:20 → 31 min → 2 blocks → 5000 (TC-03)` (прогін `ai-runs/b2-run.txt`); також `minutes` 2 ≠ 3 у TC-06 |
| **Виправлення** | `8d8749c fix(T1): неповна хвилина округлюється вгору (Math.ceil замість Math.round)` |

## Кроки відтворення

1. Взяти код із `main` (`mkdir -p ../ws12-main && git archive main app | tar -x -C ../ws12-main`).
2. Порахувати вартість поїздки класичним велосипедом 30 хв 20 с (команда нижче).

## Очікуваний результат (за специфікацією)

30 хв 20 с → неповна хвилина вгору → **31 хв** (T1, `docs/spec/tariffs.md:46-47`);
31 хв → 2 розпочаті блоки (T3, `:62`) → 2 × 2500 = **5000 коп.**

## Фактичний результат

`minutes = 30`, `timeCharge = 2500`, `total = 2500` — другий блок не відкрився.

## Доказ

```bash
cd ../ws12-main && node -e 'import("./app/src/tariff.js").then(({ quote }) => { const q = quote({ pickupAt: "2026-09-16T07:00:00Z", returnAt: "2026-09-16T07:30:20Z", bike: "classic", returnStation: "S03" }, { type: "standard" }); console.log(JSON.stringify({ minutes: q.minutes, timeCharge: q.timeCharge, total: q.total })); })'; cd -
```

```text
{"minutes":30,"timeCharge":2500,"total":2500}
```

Після виправлення та сама команда з кореня репо дає `{"minutes":31,"timeCharge":5000,"total":5000}`.

## Мінімальний вхід

Будь-яка поїздка з «хвостом» 1–29 с над цілою хвилиною на межі блоку
(наприклад, 30 хв 20 с). Зробіть «хвіст» ≥ 30 с (30 хв 30 с) — Math.round
округлить угору і дефект замаскується.

## Додатково

Причина — `Math.round` у `rideMinutes` (`app/src/tariff.js:71` на `main`).

Той самий дефект на межі T8 («понад 24 години», `docs/spec/tariffs.md:119-120`):
поїздка 24 год 0 хв 20 с за T1 триває 1441 хв, тож збір 200000 коп. належить. На
копії `main`:

```bash
cd ../ws12-main && node -e 'import("./app/src/tariff.js").then(({ quote }) => { const q = quote({ pickupAt: "2026-09-16T07:00:00Z", returnAt: "2026-09-17T07:00:20Z", bike: "classic", returnStation: "S03" }, { type: "standard" }); console.log(q.minutes, JSON.stringify(q.fees), q.total); })'; cd -
```

```text
1440 [] 30000
```

Після виправлення та сама команда з кореня репо дає
`1441 [{"code":"unreturned","amount":200000}] 230000`.
Наявний тест `app/test/unit/tariff.test.js` › «a ride of 30 min 20 s is billed
as one block» стверджував хибну поведінку — оновлено за специфікацією у тому
самому коміті. Тести «з коду» зафіксували цю поведінку як норму
(`ai-runs/b1-from-code/tariff.test.js` › «хвилини округлюються: 89 с → 1 хв…»,
червоний у `ai-runs/b1-rerun.txt`).
