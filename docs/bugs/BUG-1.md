# BUG-1: Неповна хвилина не округлюється вгору: поїздка 30 хв 1 с коштує як 30 хв

| Поле | Значення |
|---|---|
| **Правило специфікації** | T1 — «Тривалість поїздки — фактичний час, що минув від моменту взяття до моменту повернення. Неповна хвилина рахується як повна: тривалість округлюється вгору до цілих хвилин.» (`docs/spec/tariffs.md:45-46`) |
| **Середовище** | `main` (початковий код) і коміт `db486f4` (після виправлення); Node v26.13.0; Darwin 25.6.0 |
| **Серйозність** | висока — завищення/заниження тривалості зачіпає кожну поїздку, яка закінчується не на цілій хвилині; недобір до одного блоку (25–40 грн) на межі 30/60/… хв; також ламає межі T2 (хибний старт) і T8 (24 год) |
| **Частота** | завжди, коли дробова частина хвилини менша за 30 с (так працює `Math.round`) |

| **Виправлення** | коміт `db486f4` (`git log --oneline -1 db486f4`) |

## Очікуваний результат (за специфікацією)

30 хв 1 с → 31 хв (T1) → 2 блоки → 5000 коп (`docs/spec/tariffs.md:46`, `:62`).

## Фактичний результат

`minutes: 30`, `timeCharge: 2500`, `total: 2500`: 1 с відкинуто (`Math.round` у `rideMinutes`).
