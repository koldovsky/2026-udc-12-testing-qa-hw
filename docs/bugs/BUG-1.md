# BUG-1: тривалість поїздки округлюється до найближчої хвилини, а не вгору

| Поле | Значення |
|---|---|
| **Правило специфікації** | T1 — «Неповна хвилина рахується як повна: тривалість округлюється вгору до цілих хвилин.» `docs/spec/tariffs.md:45-47` |
| **Середовище** | `main` = `4606c72` (до виправлення, копія `../ws12-main`); після — коміт виправлення; Node v22.22.3; macOS (Darwin 25.6.0) |
| **Серйозність** | висока — зачіпає кожну поїздку, де після цілої хвилини минуло < 30 с: на межі блоку недоплата 25 / 40 грн; поїздка 24 год 00 хв 01–29 с не отримує збору T8 (−2 000 грн) |
| **Частота** | завжди, коли дробова частина хвилини < 30 с |
| **Знайдено** | `app/test/spec/t1-t3-duration-blocks.test.js` › `T1: TC-03 …`, `T1: TC-04 …`, `T2: TC-08 …`; `app/test/spec/t7-t8-fees.test.js` › `T8: TC-44 …` (`ai-runs/b2-run.txt`) |
| **Виправлення** | `87c1c20 fix(T1): round ride duration up to whole minutes` |

## Кроки відтворення

1. Стандартний користувач, класичний велосипед, станція `S01`.
2. Взяття `2026-09-16T07:00:00Z`, повернення `2026-09-16T07:30:29Z` (30 хв 29 с).
3. Викликати `quote()` (команда нижче).

## Очікуваний результат (за специфікацією)

30 хв 29 с → **31 хв** (T1, `:46-47`) → 2 розпочаті блоки по 25 грн (T3, `:62`, `:66`) → **`minutes: 31`, `total: 5000`**.

## Фактичний результат

`minutes: 30`, `timeCharge: 2500`, `total: 2500`.

## Доказ

```bash
node -e 'import("./app/src/tariff.js").then(({ quote }) => console.log(JSON.stringify(quote({ pickupAt: "2026-09-16T07:00:00Z", returnAt: "2026-09-16T07:30:29Z", bike: "classic", returnStation: "S01" }, { type: "standard" }))))'
```

До виправлення (`cd ../ws12-main && <та сама команда>`, код з `main`):

```text
{"minutes":30,"timeCharge":2500,"discounts":[],"fees":[],"total":2500}
```

Після виправлення (у репо):

```text
{"minutes":31,"timeCharge":5000,"discounts":[],"fees":[],"total":5000}
```

## Мінімальний вхід

Будь-яка поїздка тривалістю N хв + 1…29 с. Повернення `07:30:30Z` (30 с) — дефект зникає (`Math.round` дає 31).

## Додатково

Гіпотеза: `app/src/tariff.js:71` — `Math.round` замість `Math.ceil`. Наявний тест, що стверджував хибну поведінку: `app/test/unit/tariff.test.js` › `a ride of 30 min 20 s is billed as one block` — оновлено (див. `docs/bugs/README.md`). Тест з коду `ai-runs/b1-from-code/tariff.test.js` › `minutes are rounded to the nearest minute` зафіксував дефект.
