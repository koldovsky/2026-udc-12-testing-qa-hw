# BUG-1: Неповна хвилина округлюється вниз

| Поле | Значення |
|---|---|
| **Правило специфікації** | **T1:** «Неповна хвилина рахується як повна: тривалість округлюється вгору до цілих хвилин» (`docs/spec/tariffs.md:43-50`). Для 30 хв 20 с очікується 31 хв; T3 дає 2 блоки (`docs/spec/tariffs.md:60-70`). |
| **Середовище** | Початковий код: `main` (`4606c72`), Node `v22.23.2`, Windows. Виправлений код перевірено в робочій копії після `cd894bf`. |
| **Серйозність** | Середня: неправильна тривалість впливає на межі тарифних блоків і може недорахувати оплату. |
| **Частота** | Завжди для неповних хвилин із дробовою частиною менше 0,5; зокрема 30:20. |
| **Знайдено** | `app/test/spec/tariffs.test.js` › `T1: TC-02` і `T9: TC-21`; початковий B2-прогін. |
| **Виправлення** | `cd894bf fix(T1): round ride duration up to full minutes` — `Math.round()` замінено на `Math.ceil()`; також оновлено unit-тест межі. |

## Кроки відтворення

1. Перейти до кореня репозиторію або окремої копії `main`.
2. Виконати команду з розділу «Доказ».

## Очікуваний результат (за специфікацією)

Тривалість 30 хв 20 с округлюється до 31 хв. 31 хв — це 2 розпочаті 30-хвилинні блоки, тому `timeCharge` і `total` дорівнюють 5000 коп.

## Фактичний результат

На `main` функція повертала `minutes: 30`, `timeCharge: 2500`, `total: 2500`. Після `cd894bf` повертає `minutes: 31`, `timeCharge: 5000`, `total: 5000`.

## Доказ

```bash
node -e "import('./app/src/tariff.js').then(({quote}) => console.log(JSON.stringify(quote({pickupAt:'2026-09-16T10:00:00Z',returnAt:'2026-09-16T10:30:20Z',bike:'classic',returnStation:'S01'},{type:'standard'}))))"
```

На копії `main`:

```text
{"minutes":30,"timeCharge":2500,"discounts":[],"fees":[],"total":2500}
```

Після `cd894bf`:

```text
{"minutes":31,"timeCharge":5000,"discounts":[],"fees":[],"total":5000}
```

## Мінімальний вхід

Класичний велосипед, стандартний rider, станція `S01`, інтервал `10:00:00`—`10:30:20` UTC. Заміна повернення на рівно `10:30:00` прибирає дробову хвилину; для дефекту достатньо додати 1 секунду до неповної хвилини.

## Додатково

Початкова логіка була в `app/src/tariff.js`, `rideMinutes()`: `Math.round((returned - pickup) / 60_000)`. Пов'язаний unit-тест після виправлення перевіряє 31 хв і 5000 коп. Коміт підтверджено Git-історією: `cd894bf` змінює `app/src/tariff.js` і цей unit-тест.
