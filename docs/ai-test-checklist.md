# Чек-ліст перевірки тестових артефактів від AI

Перевірено перші чернетки [A1 — з коду](../ai-runs/a1-from-code.md) і [A2 — зі специфікації](../ai-runs/a2-from-spec.md) проти [затвердженої специфікації](spec/tariffs.md). Вердикт стосується всієї чернетки: ✅ — виконано, ⚠️ — частково, ❌ — порушено. ID у прикладах — ID чернетки, а не [наших тест-кейсів](test-cases.md).

## Чек-ліст

## Висновок

- **A1:** числові приклади T05 (30 хв класичним → 2500), T10 (30 хв електро → 4000) і F10 (обидва збори понад ліміт → 245000) узгоджуються зі специфікацією. Для прийняття у власні кейси до них додано посилання на правило й перевірено повні вхідні дані; дослівно жоден кейс не перенесено.
- **A2:** C03–C05, C21, C27, C43, C46–C49 і C52 дають корисні однозначні очікування. Перед перенесенням час переписано як ISO 8601 з offset, додано точні рядки специфікації та окремий кейс T9. Питання Q01 про включність 00:00 може бути надмірно обережним, але числового очікування A2 з нього не вигадала.
- Пункти після Task B або C: **поки немає**; доповнювати після нових спостережень, не змінюючи перші чернетки в `ai-runs/`.
