# Тест-кейси: розрахунок вартості поїздки (Велопрокат громади, тарифи v3)

> Task A. Один рядок — один тест-кейс. Очікуваний результат — **зі специфікації**
> (`docs/spec/tariffs.md`, версія 3, чинна з 2026-09-15 — `docs/spec/tariffs.md:8`), з
> посиланням на рядок специфікації. Код (`app/src/`) для очікувань не використовувався.
> Якщо специфікація відповіді не дає, це не тест-кейс, а питання (розділ «Питання до
> специфікації»).

**Умовні позначення вхідних даних.** `pickupAt` / `returnAt` — ISO 8601 зі зсувом.
Київ (`docs/spec/tariffs.md:37`): до 25.10.2026 — UTC+3 (EEST), з 04:00 EEST 25.10.2026
(остання неділя жовтня) — UTC+2 (EET). Велосипед: `classic` / `ebike`. Користувач:
`standard` / `reduced` / `subscriber`; `concession` — право на пільгу (за замовчуванням
`false`). `returnStation` — код з додатку А. Якщо не сказано інше, **раніше цієї доби
користувач поїздок не мав** (T6 не впливає). Суми — у копійках (1 грн = 100 коп).
«Погодинне» — погодинне нарахування (`docs/spec/tariffs.md:30`). Скорочений запис
`10:00:00+03:00 → 10:45:00+03:00 16.09.2026` означає `2026-09-16T10:00:00+03:00` →
`2026-09-16T10:45:00+03:00`.

Усі дати — після 2026-09-15, щоб не залежати від відкритого питання Q-7.

## Що AI вигадав

Очікування з чернеток AI, яких у специфікації немає. «Суперечить» — специфікація прямо
каже інше; «мовчки обране тлумачення» — специфікація відповіді не дає (див. питання), а
AI видав одне з тлумачень за факт.
