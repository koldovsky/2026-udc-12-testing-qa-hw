## Питання щодо неоднозначності

1. **Перетин нічного інтервалу.** T10 (рядки 139–143) визначає нічні поїздки як поїздки з 00:00 до 06:00, але не визначає розрахунок для поїздки, що частково припадає на ніч, а частково — після 06:00 (наприклад, 05:50–06:10). Чи застосовується знижка до всієї поїздки, лише до нічної частини, чи не застосовується? Очікуваний результат не фіксується.

2. **Поєднання абонемента, пільги та нічної знижки.** T5 (рядки 89–96) визначає вибір між абонементом і пільгою, а T10 — нічну знижку на погодинне нарахування, проте специфікація не встановлює порядок порівняння/застосування всіх трьох механізмів разом для абонента з правом на пільгу вночі. Очікуваний результат не фіксується.

3. **Правило T2 для рівно 2 хвилин після округлення.** T2 (рядки 54–56) посилається на тривалість за T1, однак для тривалості, що після округлення дорівнює 2 хвилинам, не наведено окремого прикладу. Формулювання «не більше 2» дає підставу вважати результат 0 коп., але для реалізації слід підтвердити, що порівнюється саме округлене значення, а не фактичні секунди.

4. **Вхід із невідомою точкою повернення.** Розділ 4 (рядки 147–149) вимагає відхилення запиту, якщо станції повернення немає в додатку A, але не визначає формат помилки та чи може такий вхід одночасно мати ознаку неповерненого велосипеда. Вартість для такого запиту не фіксується.
