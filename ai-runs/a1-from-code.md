# Тест-кейси: розрахунок вартості поїздки

Формула знижки (`tariff.js:101`):  
`discount(amount, percent) = amount − floor(amount × (100 − percent) / 100)`  
(залишок до сплати округлюється вниз, тобто знижка округлюється вгору на користь пасажира).

Зони: S01–S08 → `"in"`, X01–X03 → `"out"` (`zones.js:3–15`).  
Нічний час: `kyivTime(pickup).hour < 6` (`tariff.js:50`).  
Денний ліміт: без ledger — константа `DAY_CAP`; застосовується завжди (`tariff.js:56`).
