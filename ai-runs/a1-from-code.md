# Тест-кейси розрахунку вартості поїздки

Нижче очікування вказані саме за реалізацією у `app/src/`. Часові рядки мають явний `Z`; для нічних кейсів година трактується через `kyivTime()` у часовій зоні `Europe/Kyiv`. Стан `dayCap` у кейсах заданий явно.

## TC-01 — безкоштовний старт, 0 хвилин

- **Що перевіряється:** нульова тривалість і безкоштовний старт.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-10T10:00:00Z", bike: "classic", returnStation: "S01" }`; `rider = { type: "standard" }`; `zones = stationZones`; `dayCap` не передано.
- **Очікуваний результат:** `0` коп.
- **Джерело:** `rideMinutes()` повертає `0`; `chargeFor()` має `if (minutes < FREE_START_MINUTES) return 0`, де `FREE_START_MINUTES = 2`; зборів для 0 хв і зони `in` немає.

## TC-02 — межа безкоштовного старту, 1 хвилина

- **Що перевіряється:** остання безкоштовна хвилина.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-10T10:01:00Z", bike: "classic", returnStation: "S01" }`; `rider = { type: "standard" }`; без `dayCap`.
- **Очікуваний результат:** `0` коп.
- **Джерело:** `chargeFor()` повертає `0` для `minutes < 2`.

## TC-03 — перша платна хвилина classic

- **Що перевіряється:** перехід через безкоштовний поріг.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-10T10:02:00Z", bike: "classic", returnStation: "S01" }`; `rider = { type: "standard" }`; без `dayCap`.
- **Очікуваний результат:** `2500` коп.
- **Джерело:** `blocks(2) = ceil(2 / 30) = 1`; `RATES.classic = 2500`; інших коригувань немає.

## TC-04 — перехід на другий блок classic

- **Що перевіряється:** округлення кількості блоків угору.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-10T10:31:00Z", bike: "classic", returnStation: "S01" }`; `rider = { type: "standard" }`; без `dayCap`.
- **Очікуваний результат:** `5000` коп.
- **Джерело:** `blocks(31) = 2`; `chargeFor()` множить блоки на `RATES.classic = 2500`.

## TC-05 — ebike за один блок

- **Що перевіряється:** базова ставка електровелосипеда.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-10T10:10:00Z", bike: "ebike", returnStation: "S01" }`; `rider = { type: "standard" }`; без `dayCap`.
- **Очікуваний результат:** `4000` коп.
- **Джерело:** `blocks(10) = 1`; `RATES.ebike = 4000`.

## TC-06 — звичайний абонемент у межах 45 безкоштовних хвилин

- **Що перевіряється:** безкоштовна абонементна тривалість.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-10T10:45:00Z", bike: "classic", returnStation: "S01" }`; `rider = { type: "subscriber" }`; без `dayCap`.
- **Очікуваний результат:** `0` коп.
- **Джерело:** `subscriptionCharge()` обчислює `blocks(max(0, 45 - 45)) * 2500 = 0`; `cheaperPlan()` обирає subscription-знижку `timeCharge - 0`.

## TC-07 — абонемент classic після 45 хвилин

- **Що перевіряється:** платні блоки абонемента після allowance.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-10T10:46:00Z", bike: "classic", returnStation: "S01" }`; `rider = { type: "subscriber" }`; без `dayCap`.
- **Очікуваний результат:** `2500` коп.
- **Джерело:** базовий `timeCharge = blocks(46) * 2500 = 5000`; `subscriptionCharge = blocks(1) * 2500 = 2500`; subscription-знижка `2500`, отже due `2500`.

## TC-08 — абонемент ebike зі знижкою 20% після 45 хв

- **Що перевіряється:** спеціальна абонементна знижка для ebike.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-10T10:46:00Z", bike: "ebike", returnStation: "S01" }`; `rider = { type: "subscriber" }`; без `dayCap`.
- **Очікуваний результат:** `3200` коп.
- **Джерело:** `timeCharge = 8000`; subscription base `4000`; `discount(4000, 20) = 800`; subscription charge `3200`; знижка `4800`; total `3200`.

## TC-09 — reduced classic

- **Що перевіряється:** 50% пільгова знижка.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-10T10:02:00Z", bike: "classic", returnStation: "S01" }`; `rider = { type: "reduced" }`; без `dayCap`.
- **Очікуваний результат:** `1250` коп.
- **Джерело:** `timeCharge = 2500`; `discount(2500, 50) = 1250`; `cheaperPlan()` обирає `reduced`.

## TC-10 — subscriber з concession: обирається дешевший план

- **Що перевіряється:** порівняння subscription і reduced для абонента з пільгою.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-10T11:00:00Z", bike: "classic", returnStation: "S01" }`; `rider = { type: "subscriber", concession: true }`; без `dayCap`.
- **Очікуваний результат:** `2500` коп.
- **Джерело:** `timeCharge = 5000`; subscription charge після 45 хв: `2500`, subscription discount `2500`; reduced discount також `2500`; `reduce()` оновлює лише при `>` — першим лишається subscription, сума до сплати `2500`.

## TC-11 — нічна знижка до 06:00 за Києвом

- **Що перевіряється:** нічна знижка після планової знижки.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T02:00:00Z", returnAt: "2026-01-10T02:02:00Z", bike: "classic", returnStation: "S01" }`; `rider = { type: "standard" }`; без `dayCap`.
- **Очікуваний результат:** `1750` коп.
- **Джерело:** у Києві pickup — 04:00, що `< NIGHT_UNTIL_HOUR (6)`; `timeCharge = 2500`; `discount(2500, 30) = 750`; due `1750`.

## TC-12 — рівно 06:00: нічна знижка не застосовується

- **Що перевіряється:** виключення верхньої межі нічного періоду.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T04:00:00Z", returnAt: "2026-01-10T04:02:00Z", bike: "classic", returnStation: "S01" }`; `rider = { type: "standard" }`; без `dayCap`.
- **Очікуваний результат:** `2500` коп.
- **Джерело:** у Києві pickup — 06:00; умова `kyivTime(pickup).hour < 6` хибна.

## TC-13 — повернення поза зоною

- **Що перевіряється:** збір за out-зону.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-10T10:02:00Z", bike: "classic", returnStation: "X01" }`; `rider = { type: "standard" }`; без `dayCap`.
- **Очікуваний результат:** `17500` коп.
- **Джерело:** time due `2500`; `feesFor()` додає `OUT_OF_ZONE_FEE = 15000`; total `2500 + 15000`.

## TC-14 — неповернення після 24 годин

- **Що перевіряється:** збір `unreturned` за тривалість понад 1440 хв.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-11T10:01:00Z", bike: "classic", returnStation: "S01" }`; `rider = { type: "standard" }`; без `dayCap`.
- **Очікуваний результат:** `322500` коп.
- **Джерело:** `minutes = 1441`; `blocks = 49`; timeCharge `122500`; `feesFor()` додає `UNRETURNED_FEE = 200000`; total `322500`.

## TC-15 — рівно 24 години без збору неповернення

- **Що перевіряється:** строгий оператор `>` на межі 1440 хв.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-11T10:00:00Z", bike: "classic", returnStation: "S01" }`; `rider = { type: "standard" }`; без `dayCap`.
- **Очікуваний результат:** `120000` коп.
- **Джерело:** `minutes = 1440`; `blocks = 48`; `timeCharge = 48 * 2500 = 120000`; умова `minutes > UNRETURNED_AFTER_MINUTES` хибна.

## TC-16 — денний ліміт обрізає time charge

- **Що перевіряється:** застосування залишку денного ліміту.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-10T10:31:00Z", bike: "classic", returnStation: "S01" }`; `rider = { type: "standard", id: "r1" }`; `dayCap = createDayCap({ limit: 3000 })`, до виклику `dayCap.record("r1", "2026-01-10T09:00:00Z", 2000)`.
- **Очікуваний результат:** `1000` коп.
- **Джерело:** due `5000`; `remaining = 3000 - 2000 = 1000`; додається day-cap discount `4000`, total due `1000` (у цій реалізації `record` після розрахунку записує `1000`; зборів немає). **Очікуваний результат: 1000 коп.**

## TC-17 — денний ліміт не впливає, якщо залишку достатньо

- **Що перевіряється:** відсутність day-cap знижки при `due <= allowance`.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-10T10:31:00Z", bike: "classic", returnStation: "S01" }`; `rider = { type: "standard", id: "r1" }`; `dayCap = createDayCap({ limit: 30000 })`, попередньо на цю дату нічого не списано.
- **Очікуваний результат:** `5000` коп.
- **Джерело:** due `5000`, `remaining = 30000`; умова `due > allowance` хибна.

## TC-18 — пільгове зменшення збору за out-зону

- **Що перевіряється:** reduced-знижка застосовується і до зборів.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00Z", returnAt: "2026-01-10T10:02:00Z", bike: "classic", returnStation: "X01" }`; `rider = { type: "reduced" }`; без `dayCap`.
- **Очікуваний результат:** `8750` коп.
- **Джерело:** due після time discount `1250`; out fee `15000 - discount(15000, 50) = 7500`; total `1250 + 7500`.

## TC-19 — округлення тривалості до найближчої хвилини

- **Що перевіряється:** `Math.round()` у `rideMinutes()`.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T10:00:00.000Z", returnAt: "2026-01-10T10:01:31.000Z", bike: "classic", returnStation: "S01" }`; `rider = { type: "standard" }`; без `dayCap`.
- **Очікуваний результат:** `2500` коп.
- **Джерело:** різниця 91 с; `Math.round(91_000 / 60_000) = 2`; `chargeFor(2, "classic") = 2500`.

## TC-20 — нічна знижка та out fee при reduced

- **Що перевіряється:** послідовність планової, нічної знижки та пільгового fee.
- **Повні вхідні дані:** `ride = { pickupAt: "2026-01-10T02:00:00Z", returnAt: "2026-01-10T02:31:00Z", bike: "classic", returnStation: "X01" }`; `rider = { type: "reduced" }`; без `dayCap`.
- **Очікуваний результат:** `9250` коп.
- **Джерело:** timeCharge `5000`; reduced discount `2500`, due `2500`; нічна discount `750`, due `1750`; out fee reduced до `7500`; total `9250`. **Очікуваний результат: 9250 коп.**
