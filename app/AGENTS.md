# app/AGENTS.md

Правила для агента, що працює над тестами сервісу «Велопрокат громади» (тека `app/`).
Загальні правила репозиторію — в кореневому `AGENTS.md`; цей файл додає вимоги лише до тестів.

## Тести

| Правило (коротко) | Звідки (знахідка, файл) |
|---|---|
| Очікувані значення в тестах — зі специфікації `docs/spec/tariffs.md`, з ID правила (`T1`–`T10`) у назві тесту; ніколи — з поточної поведінки коду. | Знахідка #3 (`app/test/unit/tariff.test.js:31`), #5 (`app/test/unit/tariff.test.js:51`), #10 (`app/test/unit/server.test.js:38`) — `docs/test-quality.md`, розділ 2. |
| Не змінюй перевірку чи очікуване значення, щоб тест пройшов, не пояснивши чому. | Вимога цілісності тестів (Task C) — розділ «Що агент видалив, пропустив або послабив», `docs/test-quality.md`. |
| Один тест перевіряє один сценарій і одне правило — не поєднуй в одному тесті різні типи велосипедів, категорії користувачів чи правила (без Eager Test). | Знахідка #2 (`app/test/unit/tariff.test.js:37`) та #9 (`app/test/unit/server.test.js:29`) — `docs/test-quality.md`, розділ 2. |
| Асерція має перевіряти реальні бізнес-значення (суми, коди знижок, комісії), а не лише `ok`, `length`, `typeof` або `total <= DAY_CAP`. | Знахідки #1, #6, #7, #8, #11 — `docs/test-quality.md`, розділ 2. |
| Граничні умови тестуй явно: `>` проти `>=`, рівно 2 хв, рівно 45 хв, рівно 1440 хв, 30 хв + 1 мс. Без таких тестів виживають мутанти двох видів: заміна `>` на `>=` і заміна константи на сусіднє значення (M014, M018, M023, M067). | Task C, strengthening — `ai-runs/c-strengthen.md`; додані тести вбили M014, M018, M023 і M067. |
| Не підміняй (mock) саму тестовану функцію `quote` — тестуй реальний код, а не те, що повертає мок. | Знахідка #4 (`app/test/unit/tariff.test.js:81`) — `docs/test-quality.md`, розділ 2. |
| Ніколи не видаляй, не пропускай (`skip`/`todo`) і не послаблюй наявний тест заради зеленого прогону; тільки додавай нові тести й підсилюй наявні. | Вимога Task C — «Кожен тест, який агент видалив, пропустив або послабив — знахідка», `docs/test-quality.md`, розділ 3. |
